A extensão UX6 adiciona à console UNIDEX UX24 **faders físicos** para controlar 6 canais. \
É possível instalar até dois UX6, um em cada lateral, para cobrir os 24 canais da console.

Se você adquiriu módulos UX6 junto com a UNIDEX UX24, eles vêm de fábrica prontos para serem encaixados.

O procedimento para instalar e configurar as expansões UX6 [é detalhado neste documento](http://solidyne.dx.com.ar/DW/doc-guides/UNIDEX_expansion_UX6_ESP.pdf).
