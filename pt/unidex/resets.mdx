## Sequência de inicialização

Ao ligar a console, o UNIDEX inicia seu sistema operacional. Uma vez concluída a sequência de inicialização, a **tela principal** é exibida e são carregados:

1. O **perfil de usuário padrão.**
2. A **última cena ativa** antes do desligamento.

---

## Perfil de usuário e permissões

O perfil de usuário determina o **nível de acesso às funções** dentro da console.\
A partir da configuração, é possível definir qual perfil é carregado automaticamente ao ligar a unidade. De fábrica, a console inicia com o perfil **ADMIN**, que tem acesso completo.

### Níveis de usuário disponíveis

1. **BASIC** – Acesso restrito a funções essenciais
2. **EXPERT** – Acesso avançado (requer senha)
3. **ADMIN** – Acesso total (requer senha)

<Info>
  Durante a inicialização, **nenhuma senha é solicitada**, mesmo que o perfil padrão tenha proteção.\
  Para que o UX24 inicialize no modo restrito e exija senha para acessar funções avançadas, é necessário **alterar o perfil padrão** para um diferente de ADMIN.
</Info>

Para mais informações sobre configuração de usuários, ver: `SETTINGS → USERS`

<Info>
  As ações de reinício são ferramentas técnicas de manutenção.\
  Em condições normais de uso, **não é necessário executá-las**.
</Info>

### Opções disponíveis

- **RESET USB**\
  Reinicia apenas o estágio USB.\
  Força o sistema operacional a reconhecer novamente os dispositivos USB conectados.
- **RESET MIXER**\
  Reinicia o motor de mixagem interno do UNIDEX e a superfície de controle.\
  Não afeta a CPU nem a tela.
- **RESET DISPLAY**\
  Reinicia o computador de bordo que gerencia o **streaming** e a **interface gráfica**.
- **FULL RESET**\
  Reinicia todos os estágios do sistema.\
  Equivale a um desligamento completo e ligamento do equipamento.
- **POWER-OFF**\
  Desliga o computador interno, que gerencia a tela sensível ao toque e os serviços de streaming.\
  A console poderá continuar operando, inclusive comandada pelo Controle WEB.\
  Para desligar completamente o equipamento, aguarde alguns segundos e desligue a fonte de alimentação (no painel traseiro ou na fonte externa conforme o modelo).

<Warning>

### Desligamento da CPU

As consoles UNIDEX possuem uma **CPU interna** que deve ser **desligada de forma segura** antes de desconectar a console completamente. Esta função **não desliga toda a console**, apenas desliga a CPU principal do sistema.

  - Após desligar a CPU, **espere alguns segundos** antes de desligar a unidade por completo, para permitir o encerramento correto dos processos internos.
  - O desligamento total é realizado pela **chave mecânica** de liga/desliga (no painel traseiro ou na fonte externa, conforme o modelo).
</Warning>
