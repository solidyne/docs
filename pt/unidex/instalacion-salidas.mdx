## <Icon icon="arrow-left-from-line" iconType="solid" color="#00860b" size={22} />  Saídas analógicas

Cada saída utiliza um conector **RJ45**, que transporta os sinais **esquerdo e direito** em um único cabo. Em algumas aplicações, essas saídas estéreo podem ser configuradas como **dois canais mono independentes**. Por exemplo, os adaptadores **UDX para linhas telefônicas** utilizam as saídas mono não balanceadas para enviar sinal para as linhas de comunicação externas.

<Info>
  As saídas rotuladas como PGM e/ou REC (balanceadas) entregam a mixagem do BUS por padrão.

  Outras saídas são atribuíveis, podendo ser configuradas para entregar qualquer um dos buses de mixagem ou até mesmo redirecionar entradas (DIRECT OUT)
</Info>

## <Icon icon="arrow-left-from-line" iconType="solid" color="#00860b" size={22} />  Saídas digitais AES3

- São conectadas por cabo **RJ45–RJ45 CAT5** e adaptador **SOL-F3/XLRM**.
- Utilizam o mesmo **pin-out** das saídas analógicas balanceadas estéreo, embora **apenas o canal esquerdo seja transmitido**.
- Também suportam a conexão de sinais **S/PDIF**.
- São balanceadas com transformador.

| Saída AES | UX24 | UX18 |
| :-: | :-: | :-: |
| AES-1 | Bus PGM | Atribuível por configuração |
| AES-2 | Bus REC | Atribuível por configuração |
| AES-3 | Atribuível por configuração | Não disponível |
| AES-4 | Atribuível por configuração | Não disponível |

<Warning>
  **MUITO IMPORTANTE:**

  As **SAÍDAS** **AES3 OPERAM APENAS A 48 kHz**.

  É imprescindível **configurar o dispositivo** de gravação no Windows para **48.000 Hz** para evitar erros de compatibilidade. Para configurar a frequência de amostragem no Windows 10:

  1. Abra o menu **Configurações do sistema** e selecione **Som**.
  2. Em **Configurações de som**, abra as **propriedades do dispositivo de entrada**.
  3. Acesse **Outras configurações do dispositivo**.
  4. Na aba **Avançado**, defina a **frequência de amostragem para 48.000 Hz**.
</Warning>
