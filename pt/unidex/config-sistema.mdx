## Configurações de sistema

### **1** <Icon icon="arrow-right-long" iconType="solid" color="#ffa300" size={18} /> Entrada de Início no Ar

Define a entrada que será colocada automaticamente no ar se a console for reiniciada devido a uma falha no fornecimento de energia.\
Para entradas estéreo, pode-se selecionar qualquer um dos canais do par.

A entrada escolhida deve estar atribuída a um canal físico ou virtual. A console sempre inicia com a última cena utilizada; portanto, se a estação trabalha em modo automatizado, certifique-se de que a cena selecionada tenha atribuído pelo menos um canal com a entrada definida para "arranque automático".

A fonte de áudio conectada a essa entrada também deve ser retomada de forma autônoma.

**Barramento Padrão**\
Indica os barramentos que serão ativados no canal atribuído à entrada definida em `Start on-air input`.

**Nível**\
Nível pré-configurado, independente da posição do fader físico. Se o fader for movido, o nível mudará para o valor correspondente à sua posição atual.

### **2** <Icon icon="arrow-right-long" iconType="solid" color="#ffa300" size={18} /> Ajustes de rede (acesso remoto)

Configure a conexão de rede para o controle remoto através do Ethernet Control.\
Por padrão, a console trabalha no modo **DHCP**. O endereço IP atribuído pelo roteador é exibido na tela principal (campo _UNIDEX IP_ no setor **STATUS**).

Através deste IP, é possível acessar a console de qualquer computador na mesma LAN usando um navegador web.\
O UNIDEX incorpora um servidor HTML5 interno que fornece a interface gráfica para operar e configurar todas as suas funções.

### **1** <Icon icon="arrow-right-long" iconType="solid" color="#ffa300" size={18} /> Configurações do Relógio

Abre uma janela para ajustar a hora. O ajuste pode ser realizado de três maneiras:

1.  **Sincronização automática pela porta STREAMING**\
    Conecte a porta Ethernet STREAMING a uma LAN com acesso à Internet. A sincronização é realizada automaticamente contra um relógio padrão internacional (UTC), sem intervenção do usuário.
2.  **Sincronização automática pela porta CONTROL**\
    Conecte a porta Ethernet CONTROL a uma LAN com acesso à Internet. Isso sincroniza o relógio interno da console (*UX-Core*). Em seguida, sincronize manualmente o computador de controle (tela sensível ao toque) pressionando a opção **SYNC FROM UX-CORE**.
3.  **Ajuste manual**\
    Insira a hora manualmente em casos onde não haja acesso à Internet.

**Fuso horário**\
Defina o fuso horário correspondente no campo `Time Zone`.

## Usuários e níveis de acesso

São acessados a partir da tela **SETTINGS**, na opção **USERS**.\
A UNIDEX dispõe de vários níveis de usuário com restrições predefinidas:

- **ADMIN**
- **EXPERT**
- **BASIC**
- **GUEST** (somente na UX24)

Os perfis **ADMIN,** **EXPERT** (e BASIC na UX24) estão protegidos por senha, definida a partir desta tela.

<Warning>
  **Somente o usuário ADMIN pode modificar senhas.**
</Warning>

A senha padrão é o nome de usuário em minúsculas: admin, expert, basic (na UX18, Basic não requer senha).

#### Como iniciar com acesso restringido

A opção `DEFAULT USER` define o usuário que é carregado ao ligar a console.\
O usuário padrão é **ADMIN** e, na inicialização, o sistema nunca solicita senha.

Para **restringir o acesso** a funções avançadas, recomenda-se alterar o usuário padrão (**ADMIN**) para **BASIC** ou **EXPERT**, conforme o nível de restrição desejado.

- Se a console iniciar com o nível **BASIC**, o operador deverá inserir a senha de **EXPERT** ou **ADMIN** para acessar funções restritas.
- Se iniciar com o nível **EXPERT**, apenas as funções que requerem nível **ADMIN** são bloqueadas.
