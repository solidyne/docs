## Conexão Ethernet para controle remoto

A console possui uma **porta Ethernet** para controle remoto através de rede local (LAN).  A **interface de controle web interna** é acessada com um navegador web a partir de qualquer computador conectado à mesma rede.

### Passo 1: Conexão física

Conecte a porta **ETHERNET de controle** da UNIDEX a uma porta do **roteador**, utilizando um cabo de rede Ethernet padrão.

<Warning>
  Não confunda o conector Ethernet para **CONTROLE** com a porta Ethernet para **STREAMING**.

  <img
    src="/images/ux24/trasero-control.jpg"
    alt="Trasero RJ45 Control"
    title="Trasero RJ45 Control"
    className="mx-auto"
    style={{ width:"40%" }}
  />
</Warning>

- De fábrica, a UNIDEX está configurada no modo **DHCP ativado**.
- O roteador atribuirá automaticamente um endereço IP disponível. Este IP pode mudar ao reiniciar a console, a menos que seja configurado um IP fixo, mas normalmente isso não é necessário (se for necessário um IP estático, acesse: `SETTINGS → SYSTEM`).
- O endereço IP atual é exibido na **tela principal** da console, abaixo do nome:\
  **UNIDEX IP.**
  <img
    src="/images/ux24/unidex-ControlIP.png"
    alt="RJ45 a RCA"
    style={{ width:"45%" }}
    className="mx-auto"
  />
</Warning>

<Note>
  **Solidyne Multi-Discovery**

  Se não houver acesso físico à console, você pode [**baixar a ferramenta Multi-Discovery**](/es/unidex/unidex-discovery) que detecta dispositivos Solidyne conectados à rede.
</Note>

### **Passo 2**: Acesso pelo navegador web

De qualquer computador conectado à **mesma rede local** (preferencialmente por cabo) abra um navegador web (recomendado: **Google Chrome**) e digite o endereço IP exibido como **UNIDEX IP**.

Isso abrirá a interface web de operação e configuração da console. A interface é semelhante à exibida na **tela sensível ao toque embarcada**.

## Conexão Ethernet para serviços de streaming

1. Conectar a porta **Streaming Out** ao roteador da LAN usando um cabo Ethernet padrão.
   <Warning>
     NÃO CONFUNDIR o **conector Ethernet de streaming** com o conector Ethernet de **controle remoto**.\
     Ambos usam RJ45, mas cumprem funções totalmente distintas.
     <img
       src="/images/ux24/trasero-streaming.jpg"
       alt="Traseiro RJ45 Streaming"
       title="Traseiro RJ45 Streaming"
       style={{ width:"40%" }}
       className="mx-auto"
     />
   </Warning>
2. O roteador atribuirá um endereço IP por **DHCP**, visível na tela principal como: **Stream IP**
3. Este IP pode mudar ao reiniciar a console, a menos que seja configurado um IP fixo.
4. A configuração dos serviços de streaming pode ser realizada de duas formas:
   - Pela **tela sensível ao toque** da console.
   - De qualquer computador na rede, acessando o endereço **Stream IP** por um navegador web.
     <img
       src="/images/ux24/unidex_streaming_ip.jpg"
       alt="Unidex Streaming Ip Jp"
       className="mx-auto"
       style={{ width:"45%" }}
     />

<Note>
  **Solidyne Multi-Discovery**

  Se não houver acesso físico à console, é possível [**baixar a ferramenta Multi-Discovery**](/es/unidex/unidex-discovery) que detecta dispositivos Solidyne conectados à rede.
</Note>
