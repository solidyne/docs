<Accordion title="Technology">
- **VQR** system for reconstruction of the original voice quality.
- Active hybrid with balanced floating telephone lines, isolated from ground using Nickel-Ferrite transformers.
- 3rd order bandpass filter in the console return to improve rejection and eliminate crosstalk in conferences.
- Rejection adjustment with internal 1 kHz generator and measurement via VU meter.
- **Bluetooth 4.0 (Class2 +4dBm max.)** with WideBand Voice (HD Telephony): 20 Hz – 7 kHz in calls / 20–20 kHz in music reception.
- Supported Bluetooth profiles: HSP v1.2 / HFP v1.6 / A2DP v1.2.
</Accordion>

<Accordion title="Level Control">
- Input and output level adjustment with two LED VU meters.
- **Priority System**: grants priority to the host, attenuating the guest by 12 dB when the host speaks.
</Accordion>

<Accordion title="Inputs">
- 4 inputs: 2 for hybrid land lines (POTS) or digital telephony, and 2 wireless inputs for mobile phones via Bluetooth or VoIP phones.
- The Bluetooth inputs can be used for both mobile phones and VoIP, allowing for unlimited expansion of digital lines.
- All 4 lines can be conferenced with cross-gain control via a single fader on the console.
- The 2 physical line inputs are transformer-isolated.
- External Bluetooth antennas outside the metal chassis for greater range.
- 1 return input from the console (Mix-Minus or auxiliary bus).
- Compatible with consoles without a dedicated Mix-Minus output.
</Accordion>

<Accordion title="Call Control">
-   Via illuminated buttons with status indication and RING flash.
-   **Private Call Attention**: a Talkback button allows private conversation with the caller before putting them on-air or ending the call.
</Accordion>

<Accordion title="Input and Output Levels">
- Unbalanced input with PLUG connector. Range: –10 to +12 dBu (nominal +4 dBu).
- Level adjustment via front panel potentiometer with LED VU indicator.
- Balanced output with XLR connector, nominal level +4 dBu.
- Unbalanced stereo headphone output (PLUG).
- Direct outputs for **Telephone Line-1** and **Bluetooth-1**, unbalanced, nominal level 0 dBu.
</Accordion>

<Accordion title="Audio Performance">
**FREQUENCY RESPONSE**

- With VQR activated: 50 Hz – 12,000 Hz.
- Without VQR: from phone lines, 300 Hz – 3,400 Hz.
- From Bluetooth mobile phones: 50 Hz – 8,000 Hz (call mode) // 20–20,000 Hz (music mode).

**SIGNAL-TO-NOISE RATIO**

- With VQR activated: 70 dBA.
- Without VQR: 50 dBA.

**HARMONIC DISTORTION (THD)**

- Less than 0.2 %
</Accordion>

<Accordion title="Hybrid Rejection">
- Greater than 40 dB for +4 dBu send @ 1 kHz. Measured with a 2 km artificial line.
- Rejection adjustment with internally generated 1 kHz tone.
</Accordion>

<Accordion title="Surge Protection">
- Metal oxide varistors (SIOV).
- Supports surges up to 2,000 V in laboratory tests.
</Accordion>

<Accordion title="Power">
- Internal stabilized switching power supply, 110/220 V – 50/60 Hz.
- Power consumption: 20 W.
</Accordion>

<Accordion title="Dimensions">
- 19" rack (1U). Height: 44 mm. Depth: 230 mm.
- Front with mounting ears: 483 mm.
- Includes rubber feet for desktop use.
- Packaging: 550 × 300 × 100 mm. Weight: 3 kg.
</Accordion>
