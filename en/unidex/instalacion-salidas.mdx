## <Icon icon="arrow-left-from-line" iconType="solid" color="#00860b" size={22} />  Analog Outputs

Each output uses an **RJ45** connector, which carries the **left and right** signals in a single cable. In some applications, these stereo outputs can be configured as **two independent mono channels**. For example, the **UDX adapters for phone lines** use the unbalanced mono outputs to send signal to external communication lines.

<Info>
  The outputs labeled as PGM and/or REC (balanced) deliver the BUS mix by default.

  Other outputs are assignable; they can be configured to deliver any of the mix buses or even redirect inputs (DIRECT OUT)
</Info>

## <Icon icon="arrow-left-from-line" iconType="solid" color="#00860b" size={22} />  AES3 Digital Outputs

- They are connected using a **RJ45–RJ45 CAT5** cable and a **SOL-F3/XLRM** adapter.
- They use the same **pin-out** as the balanced stereo analog outputs, although **only the left channel is transmitted**.
- They also support the connection of **S/PDIF** signals.
- They are transformer-balanced.

| AES Output | UX24 | UX18 |
| :-: | :-: | :-: |
| AES-1 | PGM Bus | Assignable via configuration |
| AES-2 | REC Bus | Assignable via configuration |
| AES-3 | Assignable via configuration | Not available |
| AES-4 | Assignable via configuration | Not available |

<Warning>
  **VERY IMPORTANT:**

  The **AES3 OUTPUTS ONLY OPERATE AT 48 kHz**.

  It is essential to **configure the recording device** in Windows to **48,000 Hz** to avoid compatibility errors. To configure the sample rate in Windows 10:

  1. Open the **System Settings** menu and select **Sound**.
  2. In **Sound settings**, open the **input device properties**.
  3. Go to **Other device settings**.
  4. In the **Advanced** tab, set the **sample rate to 48,000 Hz**.
</Warning>
