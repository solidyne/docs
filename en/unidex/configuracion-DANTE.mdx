The UNIDEX /A67 models feature a DANTE/AES67 module that provides **16 mono inputs and 16 mono outputs** of AoIP.

Using UNIDEX on an AoIP network requires compatible DANTE connection nodes to input signals, which can be:

- Microphone preamplifiers.
- Computers playing back via DANTE VIRTUAL SOUNDCARD.
- Line-level signals, for example, coming from another DANTE console.

Any compatible DANTE interface can be connected to UNIDEX. <br />Computers can play back directly via AoIP. For this, they must be equipped with a DANTE "virtual soundcard," which is software from Audinate that provides AoIP channels over a gigabit network. These controllers are not very expensive and are widely used to interconnect computers to the console and to each other.

<Warning>
  Implementing DANTE requires knowledge of audio over IP networking.
</Warning>

## DANTE Ethernet Port Connection

### General Considerations

- The DANTE Ethernet port connects to a gigabit QoS switch using CAT5e or CAT6 cable to set up the AoIP network.
- Typically, the console will behave as the Master Clock on the network.
- UNIDEX supports redundant connection, where two separate physical networks, set up with different switches, operate in parallel. This is used in large AoIP installations to shield the transmission from failure in one of the networks. Switching between networks is automatic.
- The AoIP network can be used to connect from the REMOTE CONTROL port of UNIDEX and control the console remotely from the computers on the AoIP network.

### Configuration in the DANTE Network

In UNIDEX, the **SETTINGS - AoIP** screen reports the status of the DANTE/AES67 module and the network.

The management of input and output devices, both from the UNIDEX console and from other interfaces, for example computers, is done from a computer connected to the network running the [**DANTE CONTROLLER**](https://www.getdante.com/products/software-essentials/dante-controller/) software developed by Audinate, a software matrix that allows assigning inputs and outputs between networked devices.
