The built-in **USB** port provides a direct connection to the computer, without the need for additional audio interfaces.

- <Icon icon="arrow-right-to-line" iconType="solid" color="#008dff" size={22} /> Provides **4 stereo playback devices** (from PC to "USB inputs" on the console).
- <Icon icon="arrow-left-from-line" iconType="solid" color="#00860b" size={22} /> Provides **4 stereo recording devices** ("USB outputs" from the console to the PC).

This means the computer can **send 4 stereo signals** to the console, and **receive another 4 stereo signals** from it.

<Info>
  Although USB is technically a data port, in this context we refer to it as **USB audio inputs and outputs**.

  - The console's "**USB outputs**" correspond to **USB recording devices** in Windows.
  - The console's "**USB inputs**" correspond to **USB playback devices** in Windows. Keeping this in mind is essential for correctly understanding the signal flow.
</Info>

The signal assignment to the USB outputs (i.e., the USB recording devices in Windows) is configured from the console in the `SETTINGS → OUTPUTS` screen.

## USB Driver Installation

<Note>
  The following description refers to the **built-in USB connector** on the Rear Panel of the UX24 and UX18 models.\
  To install an **external UDX-USB adapter**, refer to the section: **UNIDEX External Adapters**
</Note>

UNIDEX requires its own USB driver for the device to be correctly recognized in Windows.

### Installation Steps:

1. Connect the console's USB port to the PC using the supplied **USB A/B** cable.

<Danger>
  Using **poor quality or damaged cables** can cause the computer to not recognize the USB device correctly or to identify it with errors.
</Danger>

2. Download the driver: [Download Center](/es/otros_docs/downloads)
3. Run the installer and follow the instructions.

### USB Devices in Windows

Once the driver is correctly installed, Windows will display:

Playback devices (outputs from the PC to UNIDEX):

- **Solidyne USB OUT 1 →** USB Input 1 (UX24)
- **Solidyne USB OUT 2 →** USB Input 2 (UX24)
- **Solidyne USB OUT 3 →** USB Input 3 (UX24)
- **Solidyne USB OUT 4 →** USB Input 4 (UX24)

Recording devices (sends from UX24 to the PC):

- **Solidyne USB IN 1 ←** USB Output 1 (UX24)
- **Solidyne USB IN 2 ←** USB Output 2 (UX24)
- **Solidyne USB IN 3 ←** USB Output 3 (UX24)
- **Solidyne USB IN 4 ←** USB Output 4 (UX24)

These outputs are assigned from the screen at: `SETTINGS → OUTPUTS`

## ASIO 3.0 Compatibility

**ASIO 3.0** compatibility allows for the shared and simultaneous use of different USB channels between different applications, even if they are not ASIO compatible.

### Advanced Application Example:

- The automation software plays music through the **USB 1** channel via WDM.
- Another processing software (such as an ASIO effects host) takes the **USB 2** return channel from the console and applies **VST effects** in real time to the microphone voices.
