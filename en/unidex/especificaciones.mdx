  <Accordion title="Inputs">

#### Analog Inputs

| Type | Quantity | Details |
| --- | --: | --- |
| MIC | 4 | \+48 V phantom power switchable per input |
| Balanced stereo line | 4 | \+4 dBu level |
| UNIDEX | 16 mono / 8 stereo | Balanced line-level inputs, with extra capabilities for connecting Solidyne UDX adapters. Allow for up to 16 additional sources (microphones, TELCO lines). |

#### Digital Inputs

| Type | Quantity | Detail |
| --- | --: | --- |
| AES3 | 4 (stereo) | Support sampling at 44.1 - 48 - 96 kHz |
| USB Audio | 4 stereo / 8 mono | 4 stereo playback devices on a computer (WDM).<br />ASIO compatible → supports 8-in mono mode. |
</Accordion>

<Accordion title="Outputs">

#### Analog Outputs

| Type | Quantity |
| --- | --- |
| Balanced stereo PGM | 2 |
| Assignable balanced stereo | 4 |
| Unbalanced (mix-minus) | 8 |
| Control Room Monitoring (speakers + headphones) | 2 stereo |
| Studio Monitoring (speakers + headphones + talkback) | 2 stereo |

#### Digital outputs

| Type | Quantity | Detail |
| --- | --- | --- |
| AES3 | 4 stereo | ONLY support 48 kHz sampling |
| USB Audio | 4 stereo / 8 mono | 4 stereo recording devices on a computer (WDM).<br />ASIO compatible → supports 8-outs mono mode. |
| Streaming AoIP | 2 stereo (RTP, Icecast/Shoutcast) |  |
</Accordion>

<Accordion title="GPIO, intercom and auxiliaries">
| Function | Specification |
| --- | --- |
| “On-air” lights | 2 outputs (Studios A and B), 12 VDC, 250 mA |
| GPI | 4 general-purpose inputs (active high 3.3 ~ 15 V) |
| GPO | 8 outputs (7 open collector; +24 V @ 250 mA; +1 × 12 VDC @ 250 mA) |
| On-air monitor | 1 unbalanced stereo input (external tuner) |
| Talkback from studios | 1 input (on Studio Box connector) |
| Command microphone | Integrated (talk-back) |
| Intercom | 4 assignable intercom buttons |
| Intercom on TELCO | PTT (talk-listen) on TELCO channels using CUE button |
</Accordion>

<Accordion title="Architecture and audio processing">
| Parameter | Value |
| --- | --- |
| Mix buses | 4 stereo buses (PGM, REC, AUX with direct assignment from surface; VBUS assignable from screen) |
| PFL | 1 PFL bus (CUE) |
| Resolution / SR | 24 bits @ 48 kHz |
| DSP processes | Fixed per input and according to type: parametric EQ (3 or 4 bands), noise gate, compressor/limiter, de-esser |
| Mix-minus / talkback | Automatic sends (TELCO) |
| Latency | 1.2 ms (analog line → analog output) / 1.4 ms (MIC with EQ + dynamics + de-esser) |
</Accordion>
