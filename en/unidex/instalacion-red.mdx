## Ethernet Connection for Remote Control

The console features an **Ethernet port** for remote control via a local area network (LAN). The **built-in web control interface** is accessed using a web browser from any computer connected to the same network.

### Step 1: Physical Connection

Connect the **CONTROL ETHERNET** port on the UNIDEX to a port on the **router**, using a standard Ethernet network cable.

<Warning>
  Do not confuse the Ethernet connector for **CONTROL** with the Ethernet port for **STREAMING**.

  <img
    src="/images/ux24/trasero-control.jpg"
    alt="Rear RJ45 Control"
    title="Rear RJ45 Control"
    className="mx-auto"
    style={{ width:"40%" }}
  />
</Warning>

- From the factory, UNIDEX is configured with **DHCP enabled**.
- The router will automatically assign an available IP address. This IP may change when the console is restarted, unless a static IP is configured, but this is usually not necessary (if a static IP is required, go to: `SETTINGS → SYSTEM`).
- The current IP address is displayed on the console's **main screen**, under the name:\
  **UNIDEX IP.**
  <img
    src="/images/ux24/unidex-ControlIP.png"
    alt="RJ45 to RCA"
    style={{ width:"45%" }}
    className="mx-auto"
  />

<Note>
  **Solidyne Multi-Discovery**

  If you do not have physical access to the console, you can [**download the Multi-Discovery tool**](/es/unidex/unidex-discovery) which detects Solidyne devices connected to the network.
</Note>

### **Step 2**: Access via Web Browser

From any computer connected to the **same local network** (preferably via cable) open a web browser (recommended: **Google Chrome**) and enter the IP address displayed as **UNIDEX IP**.

This will open the web interface for console operation and configuration. The interface is similar to the one shown on the **onboard touchscreen**.

## Ethernet Connection for Streaming Services

1. Connect the **Streaming Out** port to the LAN router using a standard Ethernet cable.
   <Warning>
     DO NOT CONFUSE the **streaming Ethernet connector** with the **remote control** Ethernet connector.\
     Both use RJ45, but serve completely different functions.
     <img
       src="/images/ux24/trasero-streaming.jpg"
       alt="Rear RJ45 Streaming"
       title="Rear RJ45 Streaming"
       style={{ width:"40%" }}
       className="mx-auto"
     />
   </Warning>
2. The router will assign an IP address via **DHCP**, visible on the main screen as: **Stream IP**
3. This IP may change when the console is restarted, unless a static IP is configured.
4. Streaming service configuration can be done in two ways:
   - From the console's **touch screen**.
   - From any computer on the network, by accessing the **Stream IP** address from a web browser.
     <img
       src="/images/ux24/unidex_streaming_ip.jpg"
       alt="Unidex Streaming Ip Jp"
       className="mx-auto"
       style={{ width:"45%" }}
     />

<Note>
  **Solidyne Multi-Discovery**

  If physical access to the console is not available, you can [**download the Multi-Discovery tool**](/es/unidex/unidex-discovery) which detects Solidyne devices connected to the network.
</Note>
