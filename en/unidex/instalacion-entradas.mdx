<Tip>
  Each input can be assigned to any of the hardware or virtual channels.
</Tip>

## <Icon icon="arrow-right-to-line" iconType="solid" color="#008dff" size="22" />  Microphone Inputs

The balanced microphone inputs support **48 V** *phantom* power. The voltage is activated/deactivated for each channel from the screen.

Each input has a **microswitch that allows reducing the preamplifier gain by –12 dB**. The switch in the down position **activates the attenuation**.

<Info>
  On the UX18, the MIC-5 input is at a fixed level.
</Info>

## <Icon icon="arrow-right-to-line" iconType="solid" color="#6f07ab" size="22" />  UNIDEX-Type Inputs

**UNIDEX**-type inputs are special inputs that, in addition to audio, carry **PoE power** and **control communication** channels to operate Solidyne **UDX** **external adapters**.

They are typically used to connect **UDX adapters** which allow adding microphones, phone lines, or mobile phones.

UNIDEX inputs can also **be used as conventional balanced inputs**. Each UNIDEX input connector contains the left and right balanced signals.

## <Icon icon="arrow-right-to-line" iconType="solid" color="#008dff" size="22" />  Balanced Analog Inputs

- Each input uses a **single** STP cable that carries the balanced **left and right** signals.
- At the end, the RJ45 is adapted to the required audio connector type (XLR, TRS, RCA).

To connect a source in **unbalanced mode**, a **suitable adapter cable** must be used, connecting:

- The signal terminal **(–)** to the cable **shield**.
- The signal terminal **(\+)** as the **hot** signal.

## <Icon icon="arrow-right-to-line" iconType="solid" color="#008dff" size="22" />  AES3 Digital Inputs

- They are connected using a **RJ45–RJ45 CAT5** cable, utilizing the **SOL-F3/XLRF** adapter.
- To facilitate wiring compatibility, they use the **same pin-out** as the balanced stereo inputs, although the cable **only uses the left channel** for the AES3 signal.
- They support **S/PDIF** signals.

<Note>
  When the streaming downmix function is enabled, the decoded audio internally replaces the **AES1** input. The **AES-1** connector on the rear panel is internally disconnected.
</Note>

## External Tuner Input

The console features a **stereo input for an external tuner** (ON AIR MONITOR) via a 1/4" TRS connector (unbalanced). This input is available in the monitoring assignment for both the Studio and Control Room, allowing direct listening of the tuned signal.

<Tip>
  For FM, it is important that monitoring in both the studios and the control booth is performed using the **processed on-air signal**, not directly from the PGM bus. This allows for the detection of actual broadcast errors and provides more comfortable listening, without the volume jumps that can occur in the direct signal.
</Tip>

<Note>
  In the **UX18**, the **ON AIR MONITOR** input can also be assigned to a channel; thus it operates as an additional auxiliary input when not used for on-air broadcast monitoring.

  When assigned to a channel, it remains available as an eligible source in the monitoring section.
</Note>
