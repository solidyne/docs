## STUDIO MONITOR Output Connector

The **STUDIO MONITOR** output connector carries the monitoring signals to the main studio (Studio A in the UX24).

**Solidyne StudioBox HD3 and HD5** monitoring bays connect directly to this output using an **RJ45–RJ45 STP** cable, with a **pin-to-pin** connection.

When a StudioBox is not used, the console includes an **RJ45 to audio connectors** adapter cable, which allows for direct connection of active speakers and headphone amplifiers in the studio.

<Warning>
  The **STUDIO MONITOR** output must not be connected using cables other than the original one or via generic RJ45 adapter cables. This can cause failures or damage to the Studio Monitor output.
</Warning>

The signals present on the **STUDIO MONITOR** connector are:

| **PIN** | **SIGNAL** |
| :-: | --- |
| 1 | Headphones Left (\+4 dBu) |
| 2 | Headphones Right |
| 3 | GND |
| 4 | ON-AIR (\+14 V) |
| 5 | Talkback to Control Room |
| 6 | VCC \+14 V |
| 7 | Speakers Left (\+4 dBu) |
| 8 | Speakers Right |
|  | \*Chassis = GND |
