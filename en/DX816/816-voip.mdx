## Connecting to a PC

The DX series is designed to work with any communication software running on a computer. From video conferencing applications like Zoom or Google Meet, to SIP line reception software such as Linphone.

The TELCO channel allows sending a **differentiated return** (mix-minus) to the computer via USB-2, which does not include the computer's own audio (playback via USB-2), preventing feedback loops.

The computer can be added to conferences with the lines managed by the TELCO channel.

<Note>
  All communication software typically has internal cancellation mechanisms, but these systems often become misaligned, generating echoes and artifacts in the audio. A mix-minus feed is necessary for reliable communications.
</Note>

<Danger>
  **USB-2 is not operational if USB-1 is not connected to an active port.**<br />If USB-1 and USB-2 are connected to **two different PCs**, USB-2 **will not** function if the **USB-1 PC** is **powered off**.<br />(Typically USB-1 is the 24/7 on-air PC).
</Danger>

## Basic Configuration

<Steps>
  <Step title="Microphones">
    Assign microphone channels to **PGM** and **REC**.
  </Step>
  <Step title="USB-2 Channel">
    Assign to **PGM** and remove from **REC**.
  </Step>
  <Step title="Telco Channel">
    Set PGM-REC selection to **PGM**
  </Step>
  <Step title="Computer">
    Configure the application with **USB-2** audio device as input/output (microphone and playback).
  </Step>
  <Step title="ON-AIR">
    The application audio enters the console via the USB-2 Channel and goes on-air with microphone return (via REC).

    <Note>
      The application may be handling a single call or a multi-participant chat. This does not affect console operation.
    </Note>
  </Step>
</Steps>

## Conference with land lines and mobile phones (Vox-IP)

<Steps>
  <Step title="Microphones">
    Assign microphone channels to **PGM** and **REC**.
  </Step>
  <Step title="USB-2 Channel">
    Assign to **PGM** and remove from **REC**.
  </Step>
  <Step title="Telco Channel">
    Set PGM-REC selection to **PGM.**<br />**Enable the VOX-IP button.** The land line/mobile phone return is sent to PGM-2 via **REC** (visible on the **REC** VU meter).
  </Step>
  <Step title="Conference">
    Raise the Telco fader to add phones to on-air; all become **interconnected**.
  </Step>
</Steps>

<Danger>
  In the **return path to computer (REC)**, do not assign **music beds**; only **MICs**.<br />The priority/AGC systems in communication applications may **attenuate** remote voices if local audio (background music) is present.
</Danger>
