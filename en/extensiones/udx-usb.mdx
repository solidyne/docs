This adapter allows connecting a computer, via USB, to an AES3 input and output.

- The AES3-1 input is not available when the streaming playback service is enabled.
- On UX24 models, AES3 outputs 1 and 2 deliver the PGM and REC signals respectively, while 3 and 4 are assignable. The UX18 has two AES3 outputs, both assignable.
- Computer installation is automatic. Windows recognizes and enables the UDX USB as a standard USB audio device for stereo playback and recording.

## AES3 Input Configuration

<Note>
  The layout and appearance of the controls shown below may vary. This does not affect the configuration procedure.
</Note>

1. On the main screen, go to the **SETTINGS** option.
2. Turn the encoder until you reach the **AES3 input** where the UDX USB is connected.
3. Set **MODE** to **STEREO**.
4. **Assign a channel** to the input. If you select a channel that's already assigned to another input, a warning will appear. If you proceed, the previous assignment will be overwritten.

## AES Output Configuration

1. On the **SETTINGS** screen, select the **OUTPUTS** option.
2. Rotate the encoder to **select the output** where the UDX USB is connected.
3. Under the **AUDIO MODE** option, configure the output as **STEREO**.
4. If the output is assignable, **SOURCE** allows selecting the signal delivered by the output.
5. Press BACK to return to the main screen.

<Danger>
  **AES3** outputs operate at **48 KHz**. In Windows, **configure the recording device** to 48 KHz.
</Danger>

### Channel Configuration

1. On the main screen, press **CHANNEL**. The CUE buttons switch to SELECT mode.
2. Press the \*\*SELECT \*\*button on the channel to configure. The console exits SELECT mode and selects the channel. To select virtual channels, rotate the encoder and press to confirm.
3. Touch the \*\*MODE \*\*menu on the screen and choose the **LINE** option.
4. To **edit the label**, touch the name. A keyboard will appear to edit the text.
5. Rotate the encoder or touch the control to select GAIN. Press the encoder to edit the value.
6. Adjust the GAIN so that peaks reach -9dBfs on the level meter.
