- The UDX TEL+BT adapter provides connection for a **land line (POTS) and Bluetooth pairing** for a mobile phone.
- It connects directly to the rear panel of UNIDEX with two SFTP RJ45-RJ45 cables (e.g. Solidyne code SOL P50).
- It is controlled from the console surface or remotely via the WEB Control interface.

UDX TEL+BT connects to one of the UNIDEX 1 to UNIDEX 4 inputs and to the corresponding output. To facilitate connection, the rear panel connectors for UNIDEX 1 to 4 inputs are aligned with their associated outputs.

### Input to output routing (mix-minus mode)

| Input | Outputs (UX24) | Outputs (UX18) |
| --: | :-: | :-: |
| UNIDEX 1 | UNBAL 5 | UNBAL 1 |
| UNIDEX 2 | UNBAL 6 | UNBAL 2 |
| UNIDEX 3 | UNBAL 7 | UNBAL 3 |
| UNIDEX 4 | UNBAL 8 | UNBAL 4 |

## Configurations

Once the **UDX 2TEL** adapter is connected, configure:

- **Inputs**
- **Outputs (sends)**
- **Channels**

### Configure Inputs

1. On the main screen, access the `SETTINGS` option.
2. **Turn the encoder** until selecting the UNIDEX input where UDX TEL\+BT is connected. If the input is currently configured as `MONO`, you will be able to select "L" and "R" individually.
3. If it is configured as `STEREO`, the L/R pair will be selected. In this case, change `INPUT MODE` to `MONO`.
   <Note>
     The "L" input corresponds to Bluetooth.\
     The "R" input corresponds to the land line (POTS).
   </Note>
4. Select the "UDX L" input. In the `UDX TYPE` option, choose `TEL+BT`.
5. Tap the screen to display the `ASSIGNED TO CHANNEL` menu to assign a CHANNEL to Bluetooth. If you choose a channel that already has an input assigned, a warning will appear. If you continue, the input on that channel is replaced.
   <Tip>
     It is recommended to assign TELCO lines to hardware channels.\
     The input gain can be adjusted **during operation** from the TELCO screen.
   </Tip>
6. Repeat from Step 4 for the "UDX R" input and assign a CHANNEL to the land line.
7. Press `BACK` to return to the main screen.
8. The next step will be to configure the output.

### Configure Outputs

1. From the main screen, access the `SETTINGS` option.
2. In `SETTINGS`, select the `OUTPUTS` option.
3. Using the encoder, select the output to which the UDX TEL+BT is connected. If the output is currently in `MONO` mode, you can individually select `OUT-L` and `OUT-R`.
4. If configured as `STEREO`, the L/R pair will be selected. In this case, change the `AUDIO MODE` to `MONO`.
   <Note>
     The "L" output is the Bluetooth send.\
     The "R" output is the phone line send.
   </Note>
5. Select `OUT-L` and set `SEND MODE` to `MIX-MINUS`. When activating `MIX-MINUS`, the output will be associated with its corresponding UNIDEX input.
6. Repeat the operation for `OUT-R`.

<Tip>
  The **send level** to the line (OUT GAIN) can be adjusted **during operation** from the TELCO screen.
</Tip>

### Channel Configuration

1. On the main screen, press `CHANNEL`. The `CUE` buttons will switch to `SELECT` mode.
2. Press the `CUE/SELECT` button for the channel you want to configure. The console will exit `SELECT` mode and display the `CHANNEL` screen for the selected channel.
3. Under the `MODE` option, open the menu and select `TELCO`. This will display the channels on the TELCO screen for call management.
4. To edit the **label**, tap on the name. An on-screen keyboard will appear for text editing.
5. Verify that the output assignment matches the UNIDEX input being used, and that the mode is set to MIX-MINUS.
6. Press `BACK` to return to the main screen.

<Warning>
  TO PERMANENTLY STORE THE SETTINGS, **SAVE THE SCENE**.
</Warning>

## Connecting UDX TEL+BT to a Phone Line

The steps to connect the land line (POTS) are:

1. Connection to the phone line.
2. Connection of an associated phone.
3. Adjustment of the rejection factor.

The procedure is detailed for the dual phone line adapter UDX 2TEL. [Click here to go to the explanation.](/es/extensiones/UDX-2TEL#Conexión-a-líneas-telefónicas)
