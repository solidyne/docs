## Overview

UDX 2MIC is a pre-amplification unit for **two microphones**.

- Features switchable _48V phantom power_ controllable from the console screen.
- On the console, it is assigned to two channels, which are configured to operate in the same way as channels assigned to the rear panel inputs.

## Wiring

The UDX 2MIC connects to the console through a **UNIDEX input**, using a straight-through STP RJ45-RJ45 cable (SOL-P50 or SOL-P25 cables).

<Danger>
  The cable connecting the UDX 2MIC to the UNIDEX input carries voltage when 48V phantom power is active. It is recommended to verify that phantom power is turned off before disconnecting it.
</Danger>

### Microphones

Microphones are connected to the UDX 2MIC adapter using standard XLR cables. If the microphones require _phantom_ power, this will be activated later from the console screen.

UDX 2MIC features **10dB input attenuation** that can be switched via dip-switches. The switches labeled A and B toggle the attenuation for inputs A and B respectively (the center switches are unused).

## UNIDEX Input Configuration

We detail the configuration from the console screen. It can also be done from the web control interface in a similar way.

1. On the main screen, access the **SETTINGS** option.
2. Turn the encoder until selecting the **channel "L"** of the UNIDEX input where UDX 2MIC is connected. "L" corresponds to channel A of UDX 2MIC while "R" is channel B.
3. By touching the screen, set **MODE** to **MONO**.
4. In the **UDX TYPE** menu choose: **2MIC**.
5. If applicable, activate **48V phantom power**. It will be activated for both inputs.
6. By touching the screen, open the ASSIGNED TO CHANNEL menu to **assign a CHANNEL** to the input. If you choose a channel that already has an input assigned, a warning will appear. If you continue, the input on that channel is replaced.
7. Press BACK to return to the main screen.
8. The next step will be to configure the channel.

## Channel Configuration

1. On the main screen, press **CHANNEL**. The CUE buttons switch to SELECT mode.
2. Press the **CUE/SELECT** button on the channel to configure. The console exits SELECT mode and displays the CHANNEL screen for the selected channel. To select virtual channels, rotate the encoder and press to confirm.
3. In the **MODE** option, open the menu and select **MIC**.
4. To edit the **label**, tap on the name. An on-screen keyboard will appear.
5. Rotate the encoder to select **GAIN**. Press the encoder to edit the value.
6. **Adjust the GAIN** of the input so that when speaking into the microphone, the peaks reach -9dBfs on the level meter.
7. By touching the screen, define the **ACTIONS** for that microphone channel. Actions allow you to:
   - Link to Master MIC A/B button
   - Link it to STUDIO A/B (determines which "ON-AIR" light is activated)
   - Define the CUE mode
   - Define the channel as Control Room microphone (determines which monitoring is muted).
8. **Save the SCENE** to register the changes.
