## Overview

The **UDX 2TEL** expansion allows connecting **two land lines (POTS)** and their associated phones.

- **UDX 2TEL-P**\
  Includes controls to **answer the line** and **transfer it to the console**.\
  This allows installing the unit and associated phones in locations remote from the console, such as a production office.
- **UDX 2TEL**\
  Has no onboard controls.\
  It's designed for calls to always be handled by the operator from the console.

All communication functions (dialing, answering, holding, talkback) are operated **from the console**.\
Each phone line operates **independently** on a channel.

## UDX 2TEL Connection

The connection is made using two standard **STP RJ45–RJ45** cables connected **pin-to-pin** (Solidyne models **SOL-P50** or **SOL-P25**).

- **Output "TO UNIDEX INPUT"** → Connect to a **UNIDEX input** (1 to 4)
- **Input "FROM UNIDEX OUTPUT"** → Connect to an **unbalanced analog output**

## Configurations

Once the **UDX 2TEL** adapter is connected, configure:

- **Inputs**
- **Outputs (sends)**
- **Channels**

### Configure Inputs

<Note>
  The layout and shape of the controls shown below may vary. This does not affect the configuration procedure.
</Note>

1. On the main screen, access the `SETTINGS` option.
2. **Rotate the encoder** until selecting the **channel "L"** of the UNIDEX input where UDX 2TEL is connected. "L" corresponds to LINE A of UDX 2MIC while "R" is LINE B.
3. Tap the screen to set `INPUT MODE` to `MONO`.
4. In the `UDX TYPE` option, select `2TEL`
5. Tap the screen to open the `ASSIGNED TO CHANNEL` menu to assign a CHANNEL to the input. If you choose a channel that already has an input assigned, a warning will appear. If you continue, the input on that channel is replaced.
   <Warning>
     It is recommended to assign TELCO lines to hardware channels.
   </Warning>
6. In the `PROCESS` section, you can preset an equalization and/or noise gate.
7. Press `BACK` to return to the main screen.
8. The next step will be to configure the output.

### Configure Outputs

1. From the main screen, access the `SETTINGS` option.
2. In `SETTINGS`, select the `OUTPUTS` option.
3. Using the encoder, select channel "L" of the output to which UDX 2TEL is connected. OUT-L = UDX 2TEL Line A OUT-R = UDX 2TEL Line B
4. In the `AUDIO MODE` option, set the output to **MONO**.
5. Configure `SEND MODE` to `MIX-MINUS`. When MIX-MINUS is activated, the output will be associated with the corresponding UNIDEX input.
6. Repeat the operation for Line B.

<Tip>
  The **send level** to the line (OUT GAIN) and the **input gain** can be adjusted **during operation** from the TELCO screen.
</Tip>

### Channel Configuration

1. On the main screen, press `CHANNEL`. The `CUE` buttons switch to `SELECT` mode.
2. Press the `CUE/SELECT` button on the channel to be configured. The console exits `SELECT` mode and displays the `CHANNEL` screen for the selected channel.
3. In the `MODE` option, open the menu and select `TELCO`.
4. To edit the **label**, tap on the name. An on-screen keyboard will appear to enter the text.
5. Verify that the output assignment indicates the output corresponding to the input being used, and that the mode is MIX-MINUS.
6. Press `BACK` to return to the main screen.

<Warning>
  TO PERMANENTLY STORE THE SETTINGS, **SAVE THE SCENE**.
</Warning>

## Phone Line Connections

Phone lines and their associated devices are connected using standard **RJ11** cables.

- Two inputs for **phone lines**
- Two inputs to connect the **associated phones**

The phones operate normally as long as the lines **are not being used by the console**.

<Warning>
  If there is **no dial tone** when seizing the phone line, verify on the **UDX TEL** adapter that the **LINE** and **PHONE** connections are not reversed.
</Warning>

### Connection Type

- Lines can be connected directly to the **public telephone exchange** or to the radio station's **PBX**.
- Private exchanges (**PBX**) slightly reduce the hybrid's rejection, so it's recommended to connect the console directly to the **public exchange**.
- **ATA GSM** (cellular) adapters can be used, which work with a GSM chip and allow connection to a conventional land line (POTS) telephone.

### Protection and Filtering

The **UDX TEL** adapters include:

- Internal **RF** rejection filters (AM, VHF and UHF bands)
- Internal protection against high-voltage surges (lightning or indirect strikes) using metal oxide varistors.

<Warning>
  Phone lines have internal protection against high-voltage surges using **metal oxide varistors**. However, it is **essential** to install **external protectors** on public exchange lines, connected to a **2 m buried grounding rod**.
</Warning>

## Null Adjustment

It is essential to adjust the **null factor** for each phone line.

- From the factory, units are calibrated to work with **ideal impedances**.
- In practice, real phone lines exhibit impedance variations.
- If the null is not optimized during on-air operation, the studio host's voice may mix with the call audio, degrading quality.

This adjustment applies to the following units:

- **UDX 2TEL**
- **UDX 2TEL-P**
- **TEL\+BT** (only for the land line (POTS))

### Adjustment Procedure

1. Press the **TELCO** button to access the Telecommunications operation screen.
2. Establish a call (can be outgoing or incoming). The microphone on the phone should be muted on the other end of the line.
3. In the `CONFIG` section of the `TELCO` screen, press `ENTER Null Adjust`. The console injects an adjustment tone into the phone line. The level at which it returns is displayed in `INPUT LEVEL`. The line does not need to be on-air (the fader can be closed).
4. The rejection is adjusted from the UDX 2TEL box. Each line has an adjustment preset.
5. Using a screwdriver, gently turn the preset clockwise and counterclockwise until finding the point where the signal return shown on the indicator is minimized.
6. Once the rejection is adjusted, terminate the communication.
7. Repeat the rejection adjustment for the other line.

<Note>
  If you change phone lines, the adjustment must be repeated.
</Note>
