The screen for user and scene management allows:

- Changing the active user.
- Changing the current scene.
- Using advanced functions to organize channels.

It is accessed by pressing the **SCENES** option, available on the contextual buttons when the console displays the **main screen**.

## USERS

In the **USER LOGIN** area (1) of the screen, the currently active user is displayed, and you can switch to another user by tapping the corresponding option.\
There are **three user levels** with different pre-set permissions. The restrictions apply both to operation from the console screen and from the remote web interface.

### BASIC User

Most restricted profile:

- No password protection.
- No access to advanced configuration options (SETTINGS).
- Can switch scenes, but cannot save changes or create new scenes.
- Can view the settings and status of the processors, but cannot modify them or turn them on/off.
- Can temporarily modify basic channel options (**GAIN**, **NAME**, **PAN**, **CHANNEL ACTIONS**), but without saving the changes to the scene.

### EXPERT User

Profile with intermediate restrictions:

- Password protected (default: `expert`). Only the ADMIN user can change it.
- Same as BASIC, without access to advanced configuration (**SETTINGS**).
- Full access to audio processes.
- On the **CHANNEL** screen, they can change **gain**, **pan**, **name**, **input assignment**, and **channel mode**, but without access to SETTINGS.
- They can save the current scene, unless it is protected.
- They can create new scenes, even from a protected one.

### ADMIN User

Profile with full access:

- Protected by password (default: `admin`).
- Can change all passwords for all profiles.
- Can create protected or read-only scenes, which are operational for BASIC and EXPERT but only editable by ADMIN.

---

<Note>
  **STARTUP USER**

  When powered on, the console starts with a predefined user profile (factory default: ADMIN) and never requests a password. To ensure access restriction from startup, change the startup user to BASIC or EXPERT.

  In `SETTINGS → USERS` you can:

  - Change the startup user.
  - **Change the passwords** for ADMIN, EXPERT, and BASIC.
</Note>

## SCENES

A **scene** stores the entire configuration of the console, with the exception of system settings (network, streaming, startup user, etc.). It includes:

- Input and output configuration.
- Channel and bus assignment.
- Gains.
- Audio processor settings.

Scenes allow you to quickly load a default configuration according to the requirements of each show; for example, by reassigning inputs, changing the channel order, or adjusting microphone processors.

<Warning>
  The scene must be saved after modifying any parameter (gain, equalizer, channel name, etc.) for the change to be stored permanently.
</Warning>

### Available Scenes

The list (see 2 in the image) shows 12 user scenes.

- Navigate by turning the encoder and confirm by pressing it.
- The active scene is highlighted in **cyan**.
- The selected scene (but not confirmed) is highlighted in **orange**.

### Protected Scenes (Lock)

- Only the **ADMIN** profile can create them.
- They are identified with a lock icon.
- BASIC and EXPERT users can load them but cannot modify or delete them.

### Scene Manager

It presents two groups of options: for the **selected scene** and for the **active scene**.

**LOAD**: Loads the selected scene. Can be done from the touch screen, context button, or encoder.

- Requires confirmation (cancels after 8 seconds if not confirmed).
- All profiles can load any scene.
- If there are channels on-air, they remain active even if they change position, maintaining their bus assignment.
- If the newly assigned channel has a different fader level, the previous digital level is maintained and indicated by flashing on the OLED.
- **Audio cuts out if the previously on-air input is not assigned** to a channel in the new scene.
- You cannot change scenes with a phone line on-air or on hold.

**RENAME**: Changes the name of the selected scene.

- Disabled for BASIC.

**COPY CURRENT**: Copies the active scene over the selected one.

- Requires confirmation.
- Disabled for BASIC.

**SET TO DEFAULT**: Restores the active scene to the factory configuration.

- Disabled for BASIC.

**SAVE**: Saves the current configuration of:

- Input assignment to the 24 channels.
- Signal assignment to the outputs.
- Specific input and output configuration (phantom, MIX-MINUS modes, etc.).
- Input and output gains.
- Channel labels and actions.
- Audio processor settings.
- Assignment status, including VBUS.

<Warning>
  The scene **does not save** the state of the **ON-AIR** or **CUE** buttons.
</Warning>

### Factory Scenes

Any of the 12 scenes can be reset to a default configuration. Furthermore, UNIDEX comes from the factory with scenes designed with different configurations and UDX expansions, intended to serve as the base or example for creating new configurations.

<Note>
  Download the [infographic on the default scene configuration](https://solidynepro.com/descargas/productos/UX24_Quickguide_Default_scenes_routing.pdf) (PDF)
</Note>

### Export and import scenes

Scenes can be exported and imported from the **WEB control interface**. \
From the scene management option in the web control, it is possible to export each scene as a file on disk. They can then be imported into any of the 12 available positions.

## Channel Map (Channel Map)

The **CHANNEL MAP** function displays the configuration of all channels and allows you to easily reorder them.\
There are two operating modes: **SWAP 2 CH** (swap two channels) and **ORDER CH** (reorder channels).

### SWAP 2 CH (Swap Two Channels)

Allows swapping the position of two channels.

<img
  src="/images/ux24/ux24-chmap.png"
  alt="UX18 Channel Map"
  title="UX18 Channel Map"
  style={{ width:"65%" }}
/>

**Procedure:**

1. Press **SWAP 2 CH** to enable the option.
2. Select the two channels you wish to swap from the list.
3. Press **APPLY** to execute the swap.
4. Press **SAVE** to save the changes to the current scene.

---

## ORDER CH (Reorder Channels)

Allows assigning new positions to one or more channels.

<img
  src="/images/ux24/ux24-OrderCH.png"
  alt="UX18 Order CH"
  title="UX18 Order CH"
  style={{ width:"65%" }}
/>

**Procedure:**

1. Press **ORDER CH**.\
   A drop-down menu will appear to the right of the channel number, allowing you to assign a new position.
2. Touch the on-screen menu and choose the new position for the channel.\
   Multiple channels can be relocated at once.

<Warning>
  If a channel is assigned a position that is already occupied, the information in the destination channel will be overwritten when the changes are applied.
</Warning>

3. Press **APPLY** to confirm.
   - **APPLY** applies the changes temporarily (they are not yet saved).
   - If you exit the scene without saving, the changes are lost.
4. Press **SAVE** to make the changes permanent in the scene.
5. To cancel, deactivate **ORDER CH** by touching the option again or press the contextual **BACK** button.
