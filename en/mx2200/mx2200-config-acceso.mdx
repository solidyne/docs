## Configuration

All Internet broadcasting options and modes can be accessed in two ways:

1.  **From the onboard screen**: using the rotary encoder (**encoder**).
2.  **Remotely (recommended)**: using a computer and a web browser.

## Web Access

<Steps>
  <Step title="Connect the console to the network">
    - **Ethernet (recommended)** via the RJ45 port.
    - Or via the **Wi-Fi antenna**.
  </Step>
  <Step title="Connect the computer">
    The computer must be on the **same network as the MX2200** and preferably using the same access method (Ethernet or Wi-Fi).

    <Note>
      Some Wi-Fi networks do not allow access to devices connected by cable (LAN).
    </Note>
  </Step>
  <Step title="Open browser and enter IP">
    Enter the **IP address** of the MX2200 (corresponding to the method used: Ethernet or Wi-Fi) in the browser.
  </Step>
  <Step title="Get the IP from the console">
    Turn the **CONTROL (encoder)** knob and access the **SETUP** screen.\
    The first three items show the connection status and the assigned IP for Ethernet, Wi-Fi and Modem.
  </Step>
  <Step title="Get the IP from the computer">
    The IP can also be found by running the **Solidyne Multi-Discovery** tool on the PC.
  </Step>
</Steps>

<Note>
     **Solidyne Multi-Discovery**

     If physical access to the console is not available, you can [**download the Multi-Discovery tool**](/es/mx2200/mx2200-discovery) which detects Solidyne devices connected to the network.
</Note>
