A **multimedia web server** is a third-party service that receives the audio broadcast from the **MX2200** and retransmits it via a public link accessible anywhere in the world, simultaneously to multiple devices.

- Subscription is typically based on the **number of simultaneous users** supported.
- Once access is configured on the console, usage is very simple: the MX2200 just needs to be connected to the Internet and the broadcast started.
- It is an ideal method when **mass distribution of the signal** is required.

<Warning>
  The **latency** in this type of transmission can vary between **5 and 30 seconds**, depending on the platform and connection. For this reason, it is only recommended when the signal is generated from the remote location **without real-time interaction** with the studios.
</Warning>

  <Tab title="Start HTTP STREAM">
    <Steps>
      <Step title="Open Connection Center">
        Turn the **encoder** to the **CONNECTION CENTER** screen and press it to enter.

        <img
          src="/images/mx2200/mx2200-connection_center.png"
          alt="Mx2200 Connection Center Pn"
          title="Mx2200 Connection Center Pn"
          style={{ width:"49%" }}
        />
      </Step>
      <Step title="Select HTTP STREAM">
        Navigate with the encoder, select **HTTP STREAM** and press to open the option.

        <img
          src="/images/mx2200/mx2200_connection_center_HTTPstream.png"
          alt="Mx2200 Connection Center HTT Pstream Pn"
          title="Mx2200 Connection Center HTT Pstream Pn"
          style={{ width:"49%" }}
        />
      </Step>
      <Step title="Enable the link">
        On the control screen, select **YES** to initiate the link with the web server.\
        When the connection is established, the **CONNECTION CENTER** and **HOME** screens will show **HTTP STREAM ENABLED**.
      </Step>
      <Step title="Terminate the link">
        Repeat the procedure and select **NO** to disable the transmission.
      </Step>
    </Steps>
  </Tab>
  <Tab title="Reception at the studios">
    Receiving a transmission via web server is the simplest method:

    - The service provider provides an **http link**.
    - The link can be opened from **any web browser** on a PC, tablet, or smartphone.
    - No additional configurations are required at the studios.
  </Tab>
</Tabs>

<Info>
  This method is ideal for **public streaming** of a station or event, allowing global access without the need for specialized software on the listeners' part.
</Info>
