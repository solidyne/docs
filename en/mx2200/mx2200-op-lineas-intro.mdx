## Overview

The **MX2200** handles:

- A conventional land line (POTS).
- A mobile phone paired via **Bluetooth**.

The primary function of both lines is to serve as a **backup link** to the Internet connection.\
They can also be used:

- As the main broadcast channel when Internet is not available.
- As an audio source to add a call to the broadcast.

## Using "On-Air" Phone Lines

- Participants (reporters or interviewees) can be added to the broadcast.
- This can be done using a land line (POTS) or a Bluetooth-paired mobile phone, even while the console is transmitting via the Internet.
- The line can interact privately with the console operator, and also with the studios when it is sent to program (PGM).
- The studio return signal (SIP) is injected into the CUE monitoring and into the send to the land line (POTS) and Bluetooth-paired phone.
- The return level of the SIP link is adjusted from the screen, in **SETUP → RX VOLUME**.

<Warning>
  **Warning!**\
  Conferencing between a land line (POTS) and a Bluetooth-paired mobile phone **is not supported**.\
  It is possible to put both lines on-air, but they will not hear each other and will not be able to converse.
</Warning>

## Phone Line as Studio Link

- Once the call is established, the studios always receive the **PGM mix** through the phone line.
- In **CUE position**, the return signal sent by the Studio is only heard in monitoring. If the TALK button for that line is pressed, the talkback microphone is sent to the studios.
- In **PGM position**, the return from the Studio is suppressed from CUE and added to PGM.
- The send to the line is **mix-minus**: the return from the Studio is not added to the PGM sent back, preventing feedback.
- In PGM position, the talkback microphone is not sent to the studio.
- Therefore, when using the line as a link, it must always be set to **PGM**, preventing the TALK mic from accidentally going on-air.
- The studio return (audio from the other end) can be heard in headphones by mixing PGM with the phone line (verify that PGM monitoring is enabled in CUE).
- If listening to the return is not needed, keep the PGM knob closed.

## Controls (Land Line (POTS) and Bluetooth)

The following controls apply both for adding calls to the local transmission and for using the lines as a studio link:

 1. **PHONE/LINE IN**
    - Switches between phone line and stereo line input.
    - With an Internet link, it is possible to operate with 4 microphones and 2 audio sources (LINE IN and USB).
    - If a call comes in on the land line (POTS), the **HOLD** button flashes. The operator can switch from LINE IN to PHONE and answer the call.

    <Warning>
      When there is no Internet and the link is made via Bluetooth, it is not possible to add from PHONE LINE, neither the land line (POTS) nor LINE IN, as **PHONE LINE is not added to the mix sent to Bluetooth**.\
      LINE IN can only be used from its own fader if there is no USB audio.
    </Warning>
 2. **Phone line / LINE IN level knob**
    - Adjusts level in both CUE and PGM.
 3. **TALK button (Land Line (POTS))**
    - Allows talking in cue with the land line (POTS) using the built-in TALK microphone.
 4. **HOLD**
    - Indicates incoming call (flashes with the ring).
    - Allows answering and putting the line on hold or sending it to PGM.
 5. **CUE/PGM**
    - Switches the signal (telephone or LINE IN) between cue listen (CUE) and program output (PGM).
 6. **Bluetooth mobile phone audio level control**
 7. **Bluetooth on/off**
    - Also activates "pairing" mode to pair a mobile phone.
 8. **Bluetooth CUE/PGM**
    - Switches Bluetooth signal between CUE listen and PGM output.
 9. **TALK button (Bluetooth)**
    - Allows talking in cue with the Bluetooth line using the built-in TALK mic.
10. **Master headphone control**
11. **PGM to Headphones**

- Removes the PGM signal from the headphones, leaving only what is present in CUE.
- Useful for dialoguing with a phone line or listening only to studio return on a SIP call.

12. **TALK to headphones button**

- Sends the voice from the built-in talkback microphone to the headphones.
