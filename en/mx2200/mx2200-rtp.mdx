The **RTP** connection offers maximum quality and low latency, but requires **network configuration** at both ends (transmitter and receiver).\
It is ideal for **fixed installations** or locations with **known and controlled networks**.

<Warning>
  **Network prerequisites**\
  Ensure you have defined the correct **IP/port** and have resolved **NAT / firewall / port forwarding** on the receiver. Without this preparation, the link may not be established.
</Warning>

<Tabs>
  <Tab title="Start RTP from MX2200">
    <Steps>
      <Step title="Open Connection Center">
        Turn the **encoder** to **CONNECTION CENTER** and press it to enter the connection options.

        <img
          src="/images/mx2200/mx2200-connection_center.png"
          alt="Mx2200 Connection Center Pn"
          title="Mx2200 Connection Center Pn"
          style={{ width:"50%" }}
        />
      </Step>
      <Step title="Select RTP STREAM">
        Choose **RTP STREAM** and press to open the RTP link screen (enable/disable).

        <img
          src="/images/mx2200/mx2200-conection_center_RTP.png"
          alt="Mx2200 Conection Center RTP Pn"
          title="Mx2200 Conection Center RTP Pn"
          style={{ width:"51%" }}
        />
      </Step>
      <Step title="Enable the link">
        Select **YES** to start the RTP link to the studios.

        <img
          src="/images/mx2200/mx2200-connection_center_RTPenable.png"
          alt="Mx2200 Connection Center RT Penable Pn"
          title="Mx2200 Connection Center RT Penable Pn"
          style={{ width:"51%" }}
        />

        When active, the **CONNECTION CENTER** and **HOME** screens show **RTP STREAM ENABLED**.
      </Step>
      <Step title="End the link">
        Repeat the procedure and select **NO** to disable the RTP.
      </Step>
    </Steps>
    <Info>
      Before starting, verify that the **network and audio format configuration** on the MX2200 matches what is expected by the receiver (destination IP, **port**, **codec**, and **sample rate**).
    </Info>
  </Tab>
  <Tab title="Return from Studios">
    The **RTP transmission is unidirectional**. Return is typically not used in this mode because the location generates the content without interaction with the studio.

    <Note>
      If you need a **return** (intercom or floor), use **a SIP call** or a **telephone communication** (Bluetooth mobile phone or POTS land line) in parallel with the RTP.
    </Note>
  </Tab>
  <Tab title="Reception in Studios (VLC)">
    To receive the streaming from an MX2200 on a **computer**, use software with **RTP** support. **VLC Player** (free) is recommended.

    <Steps>
      <Step title="Choose a compatible format">
        Configure the MX2200 with a format that the receiver supports directly:

        - **PCM16 @ 44.1 kHz** (linear)
        - **MP3** (any of the available modes)

        <Note>
          **OPUS** requires an **SDP (Session Description)** file to describe the content to the player.
        </Note>
      </Step>
      <Step title="Open network location in VLC">
        In **VLC Player**, go to **Media → Open Network Stream**.
      </Step>
      <Step title="Enter the URL">
        Use the format:

        ```
        [protocol]://[source_IP]:[port]
        ```

        Example:

        ```
        rtp://0.0.0.0:3030
        ```

        Where:

        - `rtp` is the protocol used by the MX2200.
        - `0.0.0.0` indicates "**listen from any incoming IP**" on the receiving PC.
        - `3030` is the **port** configured for reception.

        <Info>
          Some versions of VLC also accept: `rtp://@:3030`
        </Info>
      </Step>
      <Step title="Verify firewall/port">
        Ensure the configured **UDP port** is **allowed** in the system firewall and the studio router's firewall.
      </Step>
    </Steps>
  </Tab>
