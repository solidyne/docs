System updates are performed from the console's web interface:

<Steps>
  <Step title="Access the update system">
    In your browser, enter the console's IP address followed by the subpath **/update**.\
    Example: `http://192.168.0.121/update`
  </Step>
  <Step title="Check available packages">
    The screen displays the installed software packages and, if available, the latest versions ready for update.
  </Step>
  <Step title="Download update">
    Click **Download** to retrieve the latest version.\
    The package is saved to the **console's internal memory**.
  </Step>
  <Step title="Install update">
    Once the download is complete, the **Install** option becomes available.\
    Click it to start the installation process.
  </Step>
</Steps>

<Info>
  - The console allows updates even via **Wi-Fi**.
  - Since the package is stored locally before installation, the console can complete the installation autonomously.
  - The **Hardware Info** section displays **hardware** information such as the battery charge cycle count.
</Info>
