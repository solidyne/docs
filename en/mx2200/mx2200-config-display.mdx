## The SETUP Screen

The **SETUP** screen is one of the four main screens.\
It is accessed by turning the **encoder** and allows you to configure all network and broadcast options.

- The initial view shows the status of **Wi-Fi, Ethernet, and Modem**.
- For each connection, it indicates whether there is an **assigned IP** or if it is **inactive**.
- For Wi-Fi, the **network name** you are connected to is also displayed.

Pressing the encoder reveals all configuration options.

---

### SETUP → Wi-Fi

- Lists available **2.4G and 5.8G** wireless networks, sorted by signal strength.
- Signal level is expressed in **dB millivolts** (values closer to 0 = stronger signal).
- The **Wi-Fi interface MAC** appears in the top right corner.

<Note>
  Some providers require reporting the interface **MAC** to authorize the connection.
</Note>

### SETUP → Ethernet

  style={{ width:"45%" }}
/>

- Configures wired network parameters.
- From the factory, it comes with **DHCP enabled**, so it receives an IP address automatically.
- To use a **static IP**, DHCP must be disabled and the following must be assigned manually:
  - IP Address
  - Subnet Mask
  - Gateway
  - DNS Servers
- Displays the **MAC** address as informational data (not editable).

<Warning>
  Manual configuration must be performed by **qualified technical personnel**.
</Warning>

### SETUP → Modem

<img
  src="/images/mx2200/mx2200-display-setup-modem.png"
  alt="Mx2200 Display Setup Modem Pn"
  title="Mx2200 Display Setup Modem Pn"
  style={{ width:"45%" }}
/>

- Compatible with **4G dongles** (plug & play).
- Modern dongles act as Ethernet adapters and do not require configuration.
- Older 3G dongles need **APN, username, and password** parameters (provided by the ISP).
- If the connection is active, it shows an **IP address other than 0.0.0.0**.

<Warning>
  Always connect the modem using a **USB extension cable**.\
  A direct connection to the USB port can cause **audible interference**.
</Warning>

### SETUP → SIP Account

<img
  src="/images/mx2200/mx2200-display-setup-sip.png"
  alt="Mx2200 Display Setup Sip Pn"
  title="Mx2200 Display Setup Sip Pn"
  style={{ width:"45%" }}
/>

- Entry of **SIP account** data (provided by the service).
- At least **two accounts** are required:
  - One SIP address for the console. Example: `mx2200@sip.linphone.org`.
  - One SIP address for the studios, which will be configured in the VoIP software used to receive (or generate) the calls. Example: `estudio@sip.linphone.org`.

<Info>
  SIP services can be free (e.g., [Linphone](https://www.linphone.org)) or paid, depending on the complexity of the implementation.
</Info>

### SIP Audio Quality

The SIP account QUALITY setting allows you to set the preferred audio quality for SIP calls.\
Available options:

- Mono VoIP 16 kbps
- Mono Wideband 32 kbps
- Mono FM 64 kbps
- Mono HiStudio 128 kbps
- Stereo Mid 128 kbps
- Stereo HiStudio 256 kbps

<Note>
  The MX2200 prioritizes the **Opus** codec at the selected quality.\
  If the receiver does not support it, another available codec will be automatically negotiated.
</Note>

### SETUP → Power Info

<img
  src="/images/mx2200/mx2200_display_setup_power.png"
  alt="Setup - Power Info"
  title="Mx2200 Display Setup Power Pn"
  style={{ width:"45%" }}
/>

- Displays the power and battery status.
- Indicates whether the unit is using the internal battery or an external power source.
- Example: `Battery 7,0 V` → console powered by battery.
- The `Bat level` field indicates the remaining battery level (%).
- A 100% charge typically provides over 3 hours of on-air operation.
- The unit automatically shuts down when the voltage reaches **6,2 V**.
- A **12 V power bank** can be used as an external power source.

---

### SETUP → Time Zone

- Adjust the time zone to correctly assign date/time to recordings.
- Typically configured only once.
- Synchronization is performed via **public NTP servers**.

---

### SETUP → RX Volume

- Adjusts the return level sent from the station when the connection is via **SIP**.
- This return is added to:
  - CUE monitoring circuit (headphones).
  - Send to **POTS** lines.
  - Send to **Bluetooth** line.
