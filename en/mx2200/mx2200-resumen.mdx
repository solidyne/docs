## Description

The **Solidyne MX2200** codec-mixer is a compact unit for field work and remote broadcasts. It handles multiple connection technologies with simple and intuitive operation.

It can be configured from its **onboard screen** or, when connected to a network, from a computer using a web browser.

It is powered by a **12 VDC / 1.25 A** switching power supply, and its internal battery provides up to **4 hours of autonomy**.

## Link and Transmission

**Link Types:**

1. Wired Ethernet
2. Wi-Fi (using external antenna)
3. 4G LTE (using USB modem)
4. Bluetooth (to a mobile phone)
5. Land line (POTS)

**Transmission Methods:**

1. VoIP via SIP calls (full duplex)
2. Streaming to Icecast or Shoutcast servers
3. RTP streaming
4. Audio via mobile phone
5. Conventional phone call

## Recording

The MX2200 can record over **100 hours** to its internal memory in **MP3** format.\
Automatic time-based stop can be configured.

Recorded files are accessed by connecting the console to the local network and using a computer with any web browser.

## Audio Inputs

**Microphones**\
Three 100 mm faders control up to 4 dynamic microphones. \
Fader #3 handles the **MIC 3** and **MIC 4** inputs. When using both inputs, it is advisable to use microphones of the same brand and model.

Level differences between different voices are partially compensated by an **internal compressor**, which acts on the microphone mix.

**Line Inputs**\
The MX2200 has two stereo inputs for line-level signals:

- One analog input (TRS connector)
- USB port for direct connection to a computer

## Telephone Connections

The unit handles:

- One conventional phone line
- One mobile phone paired via Bluetooth

These communications can be used **as the primary link** to the studio or as a backup for the data connection (streaming or SIP).\
When not used as a link, they can be integrated into the program mix.

<Warning>
  **Warning!** CONFERENCE between the phone line and Bluetooth **is not supported**.\
  It is possible to put both lines on-air, but they will not hear each other and will not be able to converse.
</Warning>

## Monitoring and CUE

- Up to **4 headphones** can be connected to the rear panel. There is a single master volume adjustment. To obtain different levels, it is recommended to use an external headphone distribution amplifier or headphones with built-in volume control.
- An **onboard talkback microphone** allows you to speak privately to the paired mobile phone or phone line, or to send messages to the headphones.
- The monitoring circuit (**CUE**) allows you to listen to signals before sending them to the program mix, for example to talk to the lines.

**On-Air Light (Tally light)**\
If an on-air light is connected, the **HEADPHONES #1** output becomes a speaker output, as it is muted when the microphones are active, preventing feedback.

## Outputs

The MX2200 offers:

- Stereo analog output
- Stereo send via USB
- An integrated CODEC that allows simultaneous generation of:
  - A SIP communication (full duplex)
  - Two streamings: one to an IP address via RTP and another to an Icecast/Shoutcast server

The main mix includes a **stereo insert point (analog)** for connecting an external audio processor.
