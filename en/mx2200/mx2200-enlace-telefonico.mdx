When the equipment broadcasts over the Internet, a land line (POTS) or a mobile phone can be used as a backup transmission method.\
Or if the broadcast is made using a Bluetooth mobile phone, a land line can be used simultaneously as a backup transmission for the mobile phone.

The configuration of the lines to operate as links is:

<Tabs>
  <Tab title="Line as Link">
    It is also possible to use a phone line as the **main transmission channel**.

    - In the **PGM** position, the studio return is suppressed from the CUE monitoring and is added to the program mix.
    - The **TALK mic** is not sent to the studio.
    - It is recommended to use the line in the **PGM** position, to prevent the talkback microphone from accidentally going on-air.
    - If it is not necessary to hear the studio return: keep the **PGM knob closed**.
    - To hear the return: open the **PGM** knob → the studio signal is heard in all headphones monitoring the PGM mix.
    - The signal sent to the lines is in **mix-minus** mode: the signal coming from the studio is removed from the send, avoiding feedback.
  </Tab>
  <Tab title="Line as Backup">
    While the MX2200 broadcasts over **Internet**, the land line or a mobile phone can be used as a **backup method**.

    - When the line is in the **CUE** position, the studio return is sent only to the headphone monitoring.

    <Info>
      Once the call is established, the studios always receive the **PGM** mix, regardless of whether the line is in **CUE** or **PGM** mode.
    </Info>
    - If **TALK** is pressed on that line, the talkback microphone is sent to the studio via that line.
    - This condition allows the MX2200 operator to privately converse with the Studio, while the console transmits over the Internet.
  </Tab>
</Tabs>

<Note>
  More details on line operation in [Using the Phone Lines](/es/mx2200/mx2200-op-lineas-intro)
</Note>

## Reception in studios

- Phone calls are received in the studio via **telephone hybrids and conventional interfaces**.
- All **Solidyne** consoles support standard **POTS** land lines (POTS) and **Bluetooth** interfaces to pair mobile phones.
