## Program Mix

- **4 dynamic microphones** (two share the MIC 3+4 fader).
- **1 mobile phone**:
  - Can be used with a Bluetooth microphone.
  - Can be paired via Bluetooth to a second **Solidyne MX2100** console to handle multiple microphones and headphones.
- **Notebook via USB**: plays audio directly into the console, allowing all content to be generated from the remote location.

## On-Air Transmission to the Studios

The **MX2200** obtains internet access via:

- Connection to a Wi-Fi network
- Connection to a wired LAN
- 4G modem

**Link to the studio:**

- The connection is established via full-duplex **SIP calls** with no audible delay.
- Call setup is immediate: the console dials and the studio answers (or vice versa).
- A server on the internet (**Cloud Service**) initially connects both ends (1 and 2). Once established, the connection transforms into a **private tunnel (Internet Tunneling)** between the console and the studio (3).
- In parallel to the SIP call, the **MX2200's CODEC** can transmit:
  - An RTP stream to an IP address
  - Another stream to a web server (Icecast/Shoutcast), with differentiated qualities
- As a backup, the following can be used:
  - A **land line (POTS)**
  - The **Bluetooth mobile phone** (if it is not being used for program contribution)

## Reception in the studio

The SIP call is received using a computer with third-party software for VoIP account management. There are free options, such as [Linphone](https://www.linphone.org/).

## Recording

The **MX2200** can record over **100 hours** of program material in **MP3 @192 kbps** format to its internal memory.\
Recording can be activated simultaneously with broadcasting.
