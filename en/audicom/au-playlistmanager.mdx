## Auxiliary Playlists

It is possible to work with prearranged title lists (**Playlists**).\
AUDICOM features 4 auxiliary players called **PlayList Managers**, accessible via the **PLAYLIST 1** to **PLAYLIST 4** buttons in the toolbar.

## Creating and Loading Playlists

- You can drag titles from any AUDICOM window to a PlayList Manager.
- The playlist is saved as a `.txt` file in the `\Audicom\PGM` folder.
- PlayList Manager supports playlists in **.m3u** and **.plt** formats, editable with **CyberPlay Editor** (option: _Playlists_).

### How to create a playlist

1. Open a PlayList module (or use `[Alt + P]` for PlayList 1).
2. Drag titles from **Media Manager**, **InfoMusic**, **Live Assist** or **CyberPlay**.
3. Enter a name and press **Save**.

Playlists are saved in `.txt` format in `\Audicom\PGM`.

### How to load an existing playlist

- Select it from the dropdown menu at the bottom.
- To add external playlists, copy them directly to the `\Audicom\PGM` folder.

<Info>
  Titles appear in different colors based on their last broadcast date:

  - Music (Class = Music in the database): light blue background.
  - Promotional spots: yellow background.
</Info>

PlayList Manager supports CyberPlay scheduling commands:

- Text comments.
- Pauses.
- Meteor instructions.\
  These are inserted from the right-click menu.

## Preview Monitoring

- Double-click on a title or **CUE** button → playback on preview monitor channel.
- **StopCUE** button → stops playback.
- If **CUE** mode is activated from the display (double-click to the left of the counter):
  - Audio is not reported in RDS/iRDS.
  - It is also not recorded in `.air` files.

<Warning>
  This mode is not recommended in practice, but some operators use it to work directly with the console's CUE, treating each PlayList Manager as an independent player.
</Warning>

## Content Broadcasting

Each PlayList Manager can be assigned to a different audio device, defined in the **Configuration Panel**, to route it to various channels on the audio console.

- To send a title on-air: select it and press **Play**.
- Normal mode: playback stops when finished.
- Continuous mode: plays all titles sequentially.
  - Pauses can be inserted via the right-click menu.

### Playback Controls

- Progress bar: allows navigation within the file (left click).
- Slider: adjusts playback speed (**Pitch**) ±5%.
- **Insert** button: inserts the entire playlist into CyberPlay, above the yellow cursor.
  - Titles are distributed while respecting commercial breaks.
- Individual insertion: drag a title to the CyberPlay window.

<Note>
  - If no item is selected in CyberPlay, the playlist will not be inserted.
  - The comments window will display: _Define the insertion point_.
</Note>

---

## Duration Constraints

<Danger>
  If a PlayList exceeds the duration of the program block, **only the titles that fit until the block ends will be inserted**.\
  It does not extend into the next program.
</Danger>

Example:

- Insert a 1-hour PlayList at 5:30 PM in a live block that ends at 6:00 PM.
- Only titles up to 6:00 PM will be inserted.
