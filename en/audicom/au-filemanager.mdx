## Introduction

<Note>
  The **File Manager** module was discontinued starting with **AUDICOM 14 (Audicom Black)** and replaced by **Media Manager**.\
  Although it is still included in the distribution to avoid a sudden change, we recommend migrating to **Media Manager**, as File Manager will be removed in future versions.
</Note>

It is accessed from the **“+ tools”** menu in the top bar of the main desktop.\
The module is organized into tabs that display the audio files available on each terminal (local or network drives).

**Features:**

- Uses a **fixed folder structure** (external folders will be ignored).
- Files are classified by type (Music, Spots, Commercials, Effects, etc.).
- Titles can:
  - be played on-air,
  - be inserted into the programming schedule,
  - or loaded into the Live Assist instant access button panels.

<Note>
  On each terminal, only the folders declared on that terminal (**audioDrives**) are displayed.\
  Additionally, the Administrator can restrict each user's access to specific folders from **Access Levels**.
</Note>

---

## Overview

The main window displays the files in the selected folder with the following fields:\
**Artist – Title – Duration – Format – Location**.

- To view other folders: click on the top tabs (Tabs).
- If there are more than 18 folders: use the scroll buttons `<-- -->`.
- Window size and position are configurable.
- Column order can be changed by clicking on the header.
- You can also perform **quick search by letter**:
  - Example: If you press "A", the cursor positions itself on the first file starting with "A" in the active column.

---

## Title Colors (Last On-air Play)

Music files registered in the database appear in different colors based on the time since their last broadcast:

- **Red**: < 4 hours
- **Orange**: 4–12 hours
- **Green**: 12–24 hours
- **Black**: > 24 hours

The time thresholds are configured in the **Settings Panel**.

---

## Folder Colors

Each folder can be assigned a color for easier identification.

- Filters allow displaying only folders of a specific color.
- Colors are unique and valid across all terminals on the network.
- Colors are defined when creating the folder or from the **INFO** window.

<Tip>
  We recommend creating a visible reference chart in the studio.\
  Example: red = music, green = announcements, yellow = sound effects.
</Tip>

## Main Controls

### Update (Update)

`[Numeric Keypad /]`

- Refreshes the selected folder to display new files.
- By default, File Manager caches the listing when opening a folder; changes won't appear until pressing **Update**.
- The window shows the date and time of the last update.

### Insert

`[Enter]`

- Inserts the selected title into the **CyberPlay** window (above the yellow cursor).
- Also supports **Drag & Drop**.
- Multiple selected titles can be inserted at once.

### Cue Start / Stop

`[Delete]`

- Plays the selected title in **CUE**.
- Double click = play in CUE.
- Second click or Delete = play the last 5 seconds (Cue End).
- Right click = stop CUE.

<Warning>
  If the system works with **a single sound card**, there is no monitor channel.\
  In that case, double click plays the file directly **on-air**.
</Warning>

### Play

- Plays the selected track through the **Program** output (same as CyberPlay).
- If CyberPlay is already playing, the file mixes into the on-air signal.
- Includes VU meters, time counter, and position bar.

### Stop / Pause

- **Single click**: stops and pauses (can be resumed).
- **Double click**: stops completely and moves to the next file.

### Audio Edit

- Accessed from context menu or expanded window.
- Opens the file in the associated editor based on extension (.wav, .mp3, .txt).
- By default, .wav files open in **FX5**.
- If another editor is installed, Windows may assign it automatically.

### Syncro

Allows **synchronizing folders** between two locations (left/right).

Options:

- **Sync left**: copies from right → left.
- **Sync right**: copies from left → right.
- **Both**: both folders end with identical content.
