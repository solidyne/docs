## Live Assist Button Panels

The **Live Assist 1** and **Live Assist 2** modules allow instant on-air playback of audio elements.\
They are primarily used for playing **SFX, promos, jingles, and beds**.

  src="/images/audicom/au-liveassist.png"
  alt="Au Liveassist Pn"
  title="Au Liveassist Pn"
  className="mx-auto"
  style={{ width:"51%" }}
/>

- Audio elements are organized in button grids.
- Each profile contains 12 pages or tabs.
- The number of buttons per page depends on the rows and columns defined in the **Configuration Panel**.
- The panel can be resized, and button sizes adjust automatically.

Live Assist supports control from:

- Keyboard (see section _Keyboard Control_).
- External controllers via **MIDI**.

### Audio Devices

- Independent output devices can be assigned or share the same device as **CyberPlay**.
- When sharing, the mix is performed internally according to the **MIX** value.
- Assignment is done from the **Configuration Panel**.

### Video

In **Audicom Black Video**, Live Assist also supports video playback.

- It does not interrupt or overlap videos that are playing in CyberPlay or PlayList Manager.

## Output Devices

Both modules can play through internal mixing on CyberPlay or through independent outputs.\
The assignment is made from the **Configuration Panel**.

## Expanded View

You can toggle between compact and expanded views.

- The switch is made using the **Maximize** button, located in the title bar.

## Pause, Stop and Fade-Stop

- **Pause**: stops playback and allows resuming with Play.
- **Stop**: completely stops and returns to the beginning.
- **Fade-Stop**: gradually attenuates the level and then stops.

## Preview Monitoring (CUE)

- Right-click on a button → playback on dedicated **CUE** channel.
- Holding right-click >1s also activates CUE.
- Alternative method: double-click the **CUE** label on the display.

<Warning>
  Console-based CUE mode is not recommended:

  - Not reported in RDS/iRDS.
  - Not recorded in `.air` files.
  - Requires manual CUE activation/deactivation per action → error-prone.
</Warning>

## Playback Modes

Live Assist has three modes, selectable by pressing the button successively:

- **Normal**:
  - Plays once.
  - If another file is triggered, it queues (blinking text).
- **Loop**:
  - Looped playback.
  - Stops with Stop or by changing modes.
- **Instant**:
  - If another button is triggered, it interrupts the previous one.

### Chaining with on-air

- While the on-air module is stopped:
  - Trigger one or more buttons in Live Assist.
  - Then press the on-air chaining button.
- The window closes and when the sequence ends, the on-air playlist continues.

<Note>
  The same operation can be performed from the keyboard using the **spacebar** after triggering a file.
</Note>

## In and Out Markers

<Steps>
  <Step title="Activate CUE">
    Double-click the CUE label to put Live Assist in CUE mode.\
    This prevents audio from being reported in RDS or recorded in `.air` files.
  </Step>
  <Step title="Trigger button">
    Press the button you want to mark.
  </Step>
  <Step title="Define markers">
    Right-click and select **Mark In** or **Mark Out**.\
    Listen to the audio and mark at the desired moment.
  </Step>
</Steps>

## Icon Window

- Displays the name and icon of the active Live Assist profile.
- Icons are `.ico` files located in `\Audicom\LA-Icons`.
- Icons can be added or deleted as preferred.

### Private Profiles

- Private profiles are only accessible by the user who created them.
- They are identified with the owner's name.
- If another user attempts to access, a restriction message appears.

### Export / Import Page

- **Export**: saves the current page as a Playlist (`.txt`).
- **Import**: loads a Playlist into the Live Assist button panel.

The list items are loaded into buttons according to their order.

### Create Live Assist Profiles

<Steps>
  <Step title="Open creation menu">
    In the icons window, right click → **Add**.\
    Enter name and icon for the profile.
  </Step>
  <Step title="Define privacy">
    Enable the **Private** option if the profile should only be available for that user.\
    (Requires administrator authorization).
  </Step>
  <Step title="Load titles">
    Drag titles from Media Manager.\
    The button takes the color of the title's category.
  </Step>
  <Step title="Edit profile">
    To change name or icon: load the profile → right click on icon → **Edit**.
  </Step>
</Steps>

## Live Assist Configuration

### Button Panel Size

- Configured in **Settings Panel > Preferences**.
- Number of rows and columns can be adjusted.
- Larger buttons with fewer elements, smaller buttons with more elements.
- Default configuration: **4 columns x 12 rows = 48 buttons per page**.
- Font type and size can also be changed.

### Data Files

- Information is stored in `Liveass.dat` and `Liveass2.dat`.
- The path is defined in `audicom.ini`.

Example:

```ini
[Live Assist]
Grid=5 12
State=1
LastPos=0 3 0
IconPath=c:\Audicom\LA-ICONS
File=c:\Audicom\LIVEASS.DAT
LastPos2=0 0 0
```

### Icons

- Default location: `\Audicom\LA-Icons`.
- Location can be changed in `audicom.ini`.
- Icons can be freely added or removed.
