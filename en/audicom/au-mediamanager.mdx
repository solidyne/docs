## Media Management and Search

From this window, you can perform the following operations:

- View and modify information in the **Database**.
- Perform **multiple searches** (by title, artist, genre, etc.).
- **Preview (CUE)** the material.
- **Insert titles into CyberPlay** (drag & drop or insert arrow).
- Modify the **crossfade time** of the audio.
- Modify the **Intro time** of the material.
- Set **start point** (_Start_).
- Set **end point** (_End_).

## On-Air Terminal Uses

There are three main modes of operation:

1. **Program following.**
2. **Search and access** to titles in the Database.
3. **Pre-listening** to files (CUE).

### Program Tracking

- InfoMusic displays real-time information about the title currently on-air.
- The operator can **modify parameters** and **save** to the Database (**Save** button) whenever their **user profile** permits it.

### Search and Access Titles

- Press **Clear** to suspend tracking and enter **Search Mode** (the button changes to **A/Z Search**).
- Set filters (Title, Artist, Genre, etc.) and press **Search**.

**Search Results**

- Displayed in resizable **auxiliary windows**.
- A second search opens a second window; the third replaces the content of the first; the fourth replaces the second, and so on.
- To work with **a single window**, close window 1 before a new search.
- To **retain** the search in window 1 and use window 2 for new searches, close window 2 after each search.

**Insertion into CyberPlay**

- From the results window, you can **drag** titles to **CyberPlay**, or use the **Insert Arrow** (inserts over the **yellow cursor** in CyberPlay).

<Note>
  The menus (Genre, Artist, etc.) are **updated when opening** InfoMusic.\
  If new Genres/Artists are added in Production, they will not appear until **closing and reopening** InfoMusic in On-Air.\
  For more information, see **InfoMusic – Production**.
</Note>

## Fades, Intro and Start/End Markers

InfoMusic On-Air displays and allows editing of:

- **Crossfade** (crossfade) for the current title.
- **Intro** (time from musical start to voice entry).
- **Start/End** (playback **start** and **end** markers).

### Crossfade

- Crossfade times are stored in the **Database**.
- From the on-air interface, you can change them **only for the current instance** or **permanently** (using the **Save** button).
- The window displays the **title graphically** and how it overlaps with the previous/next one.
- Adjust by dragging the **blue handles** (overlap range from **0 to 5 s**).

**Application rules**

- If two titles have different times, the **shorter** one is used.
- **Fade In slope**: always 0 (the _Fade In_ value represents overlap time at the beginning).
- **Fade Out slope**: automatically adjusted based on the fade value for better artistic results.

**Change persistence**

- **Save** writes to the Database (if the profile permits).
- If not saved, changes only apply to the **current playback** of the title.

<Warning>
  Duration and crossfade modifications **only take effect** starting from the **second title** below the currently playing one.\
  If you edit the **currently playing title** or the **immediately following one**, changes are **ignored** (the system precalculates fades for performance reasons).
</Warning>

### Intro

Allows setting or modifying the **intro time**:

1. Press **Play** (on InfoMusic On-Air) to preview playback.
2. When the intro ends, press **SET** → the **INTRO** display shows the value.
3. If you press **SET** with CUE stopped, the value resets to **0**.
4. Fine adjustments with the **arrow buttons**:
   - **Left button**: **1 s** steps.
   - **Right button**: **0.1 s** steps.
   - Holding the button accelerates the change.
5. Press **Save** to persist (subject to permissions).

<Note>
  **Intro** times are typically set in the **Production/Recording Terminal**.
</Note>

### Start Time

- Play in **CUE** (InfoMusic On-Air Play) and press **SET** at the desired point.
- **SET** with CUE stopped → returns to **0**.
- Precision shortcuts: **CTRL + Left/Right Arrows**
  - The preview enters a **0.5 s loop**.
  - Repeated presses move the **START** marker in **0.5 s** steps.
- **Save** to persist (if the profile allows).

### End Time

- Play in **CUE** and press **SET** where the track should **end**.
- **SET** with CUE in Stop → display shows **0**.
- Shortcuts: **CTRL + Left/Right Arrow**
  - **0.5 s** loop for precision.
  - Adjusts the **END** mark in **0.5 s** steps.
- **Save** to persist (if the profile allows).

## Keyboard Operation (InfoMusic Functions)

- **F5 – Search**: executes the search with the loaded parameters.
- **F6 – Clear Fields**: suspends tracking, enters **Search** and clears all fields (except **Class**).
- **F7 – Style**: opens the **Style** menu (navigate with arrows, confirm with Enter).
  - If it was in tracking, it switches to **Search** while retaining only **Style**.
- **F8 – Genre**: same criteria, for **Genre**.
- **F9 – Author**: same criteria, for **Author**.
- **F10 – Performer**: same criteria, for **Performer**.
- **F11 – Top Hit**: same criteria, for **Top Hit**.
- **F12 – Open/Close InfoMusic**.
- **CTRL + Left/Right Arrows**: moves **START/END** markers (depending on which is active) in **0.5 s** steps.

<Info>
  Example of using F7 during tracking:\
  If a track categorized as "Classics-Pop" is playing and you press **F7**, InfoMusic clears all fields except **Style = Classics-Pop**.\
  Then **F5** returns all titles of that style.
</Info>
