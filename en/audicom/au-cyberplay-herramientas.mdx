### Load PGM ON/OFF

- With **Load PGM** enabled (default setting), CyberPlay builds the final program using the schedules created in **CyberPlay Editor** (`.pgm` files).
- If **Load PGM** is disabled, CyberPlay ignores `.pgm` files and uses only commercial breaks.

  The operator can insert content between breaks or use **Playlist Manager**.

<Note>
  In the Configuration Panel, you can enable AUDICOM to automatically remove **gaps** at the end of each commercial block.
</Note>

### Reload: Schedule Changes

- CyberPlay automatically loads programming files every day.
- The daily loading of **LOG** and **PGM** occurs at **18:00** (configurable in the Control Panel).
- You can **manually reload** the schedule for last-minute changes.

When to use Reload:

- Modifications to the current day's schedule.
- Modifications to the next day's schedule after the automatic reload time.

Usage:

- The operator presses **RELOAD** or uses the shortcut `[Alt + R]`.
- During reload:
  - The current track continues playing but disappears from the CyberPlay window.
  - Upon completion, the green cursor positions itself on the most suitable item based on the current time.
  - The operator can:

    Force playback with Play.

    Take no action: the system will continue with the new schedule after the current track ends.

<Note>
  - If the **LOG** is modified, the RELOAD button flashes to indicate the change.
  - If a **PGM** or next day's LOG is modified, the system does not alert: the **operator must be notified** to reload.
  - You can also reload a single file (LOG or PGM) by double-clicking the corresponding field in the CyberPlay display.
</Note>

### Save Log and autoLog

- Changes to commercial blocks are automatically saved to the **LOG** file (_autoLog_ function).
- AutoLog **does not save** changes if:
  - The user is not authorized to modify blocks.
  - The LOG was modified externally and the alarm is active (Reload button flashing).

The **Save LOG** button allows manual saving:

- Even if the file was modified externally.
- It will not work if the user lacks permissions.
- Prompts for confirmation before overwriting.

### Next Title Button `[Enter]`

- Selects the title marked with yellow cursor as the **next title** (green cursor).
- If no title is selected, the next one will be below the red cursor (currently playing).
- Can be selected by double-clicking in the schedule area (left column).
  - Double-clicking in the colored area plays in **CUE**.

### Insert AutoDJ

Inserts an **AutoDJ** block into the programming schedule.

- The user defines the **format**, start time and end time.
- Commercial breaks included within the range remain intact.

### Mix `[Asterisco]`

Controls the attenuation of CyberPlay when another module (e.g. Live Assist) plays back on the same output.

- Available values: **100%, 50%, 25%, 10%** (cycle through by pressing the button).
- During video playback:
  - The attenuation only affects the video's audio.
  - If another module is also playing video, only the audio is mixed.

### Right-Click Menu Options

Pressing the right mouse button on a title displays these options:

- **CUE**: playback in preview.
- **CUE End**: plays the last 5 seconds.
- **Play**: starts playback respecting crossfade on music tracks.
- **Stop**: stops playback.
- **Fade & Play**: attenuates current audio and starts the next.
- **Fade & Stop**: attenuates current audio and stops it.
- **InfoMusic**: loads the title into InfoMusic (only if present in the database).
- **Internet…**: opens browser to search for title information.
- **Copy TANDA**: copies the content of a TANDA.
- **Insert TANDA**: inserts empty TANDA.
- **Insert Meteor**: inserts Meteor instruction.
- **Insert Pause**: inserts pause above the selected title.
- **Insert Random**: randomly selects an audio file from a defined folder.
- **Remove**: deletes the item from the schedule.
- **Remove all equal**: removes all instances of that item.
