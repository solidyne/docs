The UX24 consoles can generate **two independent audio streams** and decode an incoming audio stream.

### Available Streaming Types

- **Streaming 1 (outgoing)**\
  Uses the **RTP** protocol, ideal for transmitter link (**STL**).
- **Streaming 2 (outgoing)**\
  Compatible with **Shoutcast/Icecast servers** for internet broadcasting.
- **Streaming 3 (incoming)**\
  Can be **RTP** or a **public HTTP stream**.\
  When this function is enabled, the received audio is **automatically decoded and switched**, replacing the **AES-1** input.

### Signal Source and Send Level

The streaming uses the **PROGRAM** signal taken from the **AES-1** output, both for uploading to **Icecast/Shoutcast** servers and for the **RTP** audio stream.

The default output level (gain=0) is **-20 dBfs** referenced to **0VU** (1 kHz @ 0VU = -20 dBfs).\
Gain is adjusted from the **SETTINGS → OUTPUTS** screen.

<Warning>
  If you change the gain of the **AES-1** output, the streaming send level will also be modified.
</Warning>

## Streaming Services Configuration

It is accessed from the **SETTINGS** screen under the **STREAMING** option. \
It features four tabs to configure outgoing streaming services (UP-STREAM and RTP Link); incoming streaming (DOWN-STREAM); and network options.

### UP-STREAM (TX)

The **UP-STREAM** tab allows you to configure a **Icecast** or **Shoutcast** streaming server to broadcast the program signal.

### UP-STREAM Icecast/Shoutcast

- **ENABLE/DISABLED**: Enables or disables the streaming transmission when changes are confirmed by pressing **APPLY**.

  <Tip>
    To optimize system resources, keep it stopped when the service is not in use.
  </Tip>
- **PROTOCOL**: Defines whether the server is Icecast or Shoutcast type.
- **SERVER IP**: Destination IP address of the server.
- **PORT**: TCP listening port of the server.
- **MOUNTPOINT**: Unique name identifying the stream on the server.
- **Stream NAME**: Name identifying the stream.
- **CODEC**: Audio format for transmission (Opus or MP3).
- **QUALITY**: Bitrate for encoding.
- **PASSWORD**: Access key for publishing (if applicable).
- **APPLY**: Applies and saves changes, and starts or stops the broadcast (according to ENABLE/DISABLED status).

<Note>
  The configuration parameters for Icecast/Shoutcast are provided by the server provider.
</Note>

### RTP LINK

The **RTP LINK** tab allows configuring streaming to a specific IP address, for example, to send the program signal to a transmitter site (**STL**).

<Warning>
  Implementing an RTP link requires advanced networking configuration knowledge.
</Warning>

<img
  src="/images/ux24/ux24-config-rtplink.png"
  alt="UX24 RTP Link Configuration"
  title="UX24 Config RTP link"
  style={{ width:"62%" }}
/>

- **ENABLE/DISABLED**: Enables or disables RTP streaming when changes are confirmed by pressing **APPLY**.

  <Tip>
    To optimize system resources, keep disabled when the service is not in use.
  </Tip>
- **DESTINATION ADDRESS**: Destination IP address.
- **PORT**: TCP transmission port.
- **CODEC**: Audio format for RTP (**PCM** / **MP3**).
- **QUALITY**: MP3 bitrate or PCM sample rate.
- **GPO**: Enables sending **on-air light (Tally Light)** signals via TCP/IP for compatible Solidyne equipment.
  - **Studio A and B** (lines 1 and 2 respectively)
  - **Studio B and A** (reversed order)
  - **A+B** (signal activates on both lines regardless of active studio)

### Down-Stream (RX)

Allows configuration of an incoming _streaming_. When the **DOWN-STREAM** module is enabled (**ENABLE**), the decoded audio is internally routed to the **AES-1** input, which changes its name to **STREAM-1**.\
In this mode, the rear panel AES-1 connector is disabled.

- **RUN/STOP**\
  Starts or stops the _streaming_ decoding when changes are confirmed with **APPLY**.

  <Tip>
    To optimize system resources, keep it stopped when the service is not in use.
  </Tip>
- **PROTOCOL**\
  Defines the type of incoming _streaming_. The following formats are supported:
  - Public **HTTP** and **MMS** streams encoded in PCM 16 (44.1/48 kHz), MP3 or Opus.
  - **RTP** streams in PCM 16 (44.1 kHz) and MP3.
- **SERVER URL/IP**\
  Name or IP address of the server generating the _streaming_.
- **PORT**\
  TCP port where the _streaming_ is received.\
  Default value: **0**.
- **MOUNTPOINT**\
  Unique name identifying the _stream_.
- **APPLY**\
  Applies configuration changes.

<Note>
  **Step by step** Download a step-by-step guide for [configuring an incoming stream](http://solidyne.dx.com.ar/DW/doc-guides/UNIDEX_AplicationNote-Incoming_streaming.pdf).
</Note>

### Network (Streamer Module)

General network settings for the **Streamer UX24** module (not to be confused with web control access).

By default, the IP address operates in dynamic mode (DHCP). The assigned address is displayed on the main screen as **STREAM IP**.
